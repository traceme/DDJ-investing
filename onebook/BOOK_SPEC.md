# 《读道德经悟投资心法》书稿规格（一书为源）

## 0. 定位

从 2026-09-20 起，本书是本项目**唯一的书**，也是唯一的法源。其他十三本在本书完稿并通过 `--strict` 校验后一次性退役（md／epub／pdf 移入 `archive/`，下载链接删除，README 只留本书；git 历史保留）。2026-09-20 完稿并通过 `--strict`，EPUB／PDF 已生成并登记在 `scripts/build_system_epub.py` 与 `scripts/build_pdf.py`（版本键 `onebook`）；退役步骤等作者另行确认后执行，在此之前十三本原样保留。

- 以《道德经》八十一章为纲，每章之下写清这一章在投资里是什么、案例账户走到这里发生了什么、由此长出的规矩、今天做的事、要反复练的动作。
- 文字从头写；现有 360 条纪律、打法规则、36 条练习、参数、军规、系统条款、两本指南是**素材**，允许增删改后写进本书。
- **不用编号。** 不出现 `Cxx-nnn`、`Rx.y`、`Tx.y`、宪N、S0–S4、P0–P8。规矩是什么就写什么，出处直接引原文。
- **原文直接引进来。** 《道德经》句子用 `<mark>…</mark>`，逐字出自本章原文（引他章时前文 30 字内注明「《道德经》第N章」）。原书两本 81 章书的实操建议用「原书的实操建议：「…」」，逐字。三眼用「三眼说：「…」」，逐字出自 `thethirdeye/` 笔记（笔记是本项目文字）。金冰只许「金冰说，大意是……」转述，不逐字引用（第三方付费著作，笔记里的逐字引文不再转引）。
- 读者是「你」；案例账户＝100 单位，无真实金额；不荐股；公司只作方法示例。

## 1. 结构

```
# 读道德经悟投资心法
## 总纲            这一本书／怎样读／三本书各自教什么／十二条根本规矩／五种状态／参数表／一年的日历／案例账户
## 第一章 · 核心句  ……八十一章
## 附录            `附录-不系于某一章的规矩.md`：三眼、金冰中没有《道德经》章句之家的规矩，按五组写全（validate 对附录同样查引文、编号、PII，并计入吸收）
## 免责声明
```

每章六块，顺序固定，缺则不出现（心法、纪律、实操必有）：

| 块 | 写什么 | 长度参考 |
|---|---|---|
| 原文 | 装配器自动插入，王弼本逐字 | — |
| 心法 | 这一章在投资里说什么；三本书在此相遇处；结尾一句对仗式收束 | 1,200–2,200 |
| 案例 | 案例账户走到这一章时的事，数字与参数表一致、可复算 | 400–900 |
| 纪律 | 加粗一句条文 + 说明 + 出处原文；违反有处置 | 每条 60–150，一章 4–12 条 |
| 实操 | 今天做的一件事，优先无为安装：券商设置、日历、转账规则、第二把钥匙 | 200–500 |
| 练习 | 名称／什么时候做／做什么／数什么／达标 | 每条 40–100 |
| 研究与努力方向 | 两本指南拆到适用的章；不适用不出现 | 视章 |

单章 2,500–12,000 字（不计空白），超过 9,000 在阅读日历上标「可分两天」。

## 2. 校验（`python3 onebook/validate.py`，完稿用 `--strict`）

结构与块序；原文逐字；`<mark>` 逐字；三眼引文逐字出自笔记；实操建议引文逐字出自原书；金冰无逐字引用；无编号；通用 PII（邮箱、三位数以上「万」、千分位金额、M／K、`$` 价格）；单章长度；总纲十二条与五状态齐全；素材吸收进度（每章源文件首行 `<!-- 吸收：… -->` 登记该章吸收了哪些旧素材；`--strict` 要求 360 条纪律、151 章三眼、72 篇金冰、81+81 章实操、32 条军规全部登记）。

## 3. 参数

全书参数只在总纲的参数表定义一次，各章按名称引用。改参数只改总纲。

## 4. 文件与命令

- `onebook/book/00-总纲.md`、`onebook/book/NN.md`（`# 第X章 · 核心句` 起，H2 为块）、`onebook/book/附录-*.md`、`onebook/book/Z-免责声明.md`
- `python3 onebook/assemble.py [--stats]` → `读道德经悟投资心法.md`
- `python3 onebook/validate.py [--strict]`
- EPUB／PDF：完稿后在 `scripts/build_system_epub.py`、`scripts/build_pdf.py` 登记 `onebook` 版

- 定调后按 1→81 顺序，每批约 8 章，每批装配、校验、读过再进下一批。
