# 第二章 · 状态机：今天允许做什么

> 知和曰常，知常曰明。　——《道德经》第五十五章

三百六十条纪律的形式都是「触发→动作」，但同一个动作的合法性取决于你在哪里：买入在常态合法，在警戒非法，在停手违宪；加仓在持有·正常需要四条件，在回撤协议里根本不在选项中。状态机把这件事做成一张表：先判定账户在哪个状态、每个持仓在哪个状态，再查今天允许的动作集合。判定用的全是可以在收盘后五分钟内读出的数字与记录，不需要判断。

两级状态：**账户状态**管你——你有没有资格交易、以多大规模；**仓位状态**管每一笔——它处在生命周期的哪一段、这一段允许什么。账户状态的转移由第三章的记点与本章的数字触发；仓位状态的转移由手册的八个决策点触发。

**「当周削回」与 R7.4 的分工，以及上限的量纲。** 算式上限是**买入时点**的上限：这一笔买完后它占账户几成。持有中因上涨造成的权重漂移**不算超限**——处置它的是减仓阶梯（R6.1），不是宪二。三种情形才需要削回：

| 情形 | 处置 | 理由 |
|---|---|---|
| 买入或加仓造成成交后权重 > 算式上限 | 当周削回，一次到位 | 你自己造成的，当周纠正 |
| 季度复核日重算上限后现有权重 > 新上限 | 按 R7.4 分三次、间隔 ≥ 5 个交易日 | 不是你造成的，给市场时间 |
| 任何时点权重 > 生存上限（承受线 ÷ 可信最大跌幅） | 按 R7.4 分三次 | 最坏路径会击穿承受线，必须降 |
| 系统启用前的遗留超限 | 按 R7.4 分三次 | 同上 |

证伪触发不受此限，一律按宪五三日内足量执行。

### S3 的九个触发与各自的出口

「回到限内」只对数字型触发有意义。计数型触发要么等计数期结束，要么等固定时长。

| 触发 | 类型 | 出口 |
|---|---|---|
| 现金 < 两成（热区 < 三成） | 数字 | 回到限内并保持一周。**处置分两段**：现金在下限与下限 −5 个百分点之间只禁买入、不强制卖出（留给分红、工资、阶梯自然补足）；跌破下限 −5 个百分点（两成线 → 15%，热区三成线 → 25%）才强制卖出，按 R8.1 组合尺口径削最弱论点（腿验证数最少者，并列时权重最大者） |
| 同因子敞口 > min(60%, 承受线 ÷ 因子内最大可信跌幅) | 数字 | 同上 |
| 任一持仓 > 生存上限，或买入后 > 算式上限 | 数字 | 同上 |
| 宪七信号出现而未减到位 | 数字 | 减到上限当日即出 |
| 当季乙级记点 ≥ 3 | 计数 | 一周；期内再记 1 点则重新计时 |
| 本月成交 > 3 笔 | 计数 | 到本月末（下月另有 S4 一周，§2.1） |
| 连赢三笔 | 计数 | 一周（暂停加仓并重算仓位，§4.20） |
| 持仓人声鼎沸（＝D6「身边谈股人数」项：本月主动问你股票的圈外人 ≥ 3）；月度自查想不起最近哪次下跌让自己紧张（月表布尔字段） | 计数 | 到下一个月度自查日 |
| 账户创新高且季度判为热区 | 计数 | 降一成仓位、清杠杆后即出；热区本身不进 S3 |

**热区不等于 S3。** 热区（季度五问 ≥ 3 问答「热」，R18.20）只做一件事：把现金下限从两成抬到三成。抬线之后现金若不足，是「现金 < 三成」这个**数字**把你送进 S3，不是热区本身。所以热区里你仍可按预写批次买入——只要现金仍在三成以上。

**状态优先级：S4 > S3 > S2。** 同时满足时按最高的执行。退出 S4 时重新评估 S3 的九个触发，仍在则进 S3。同一个记点不重复触发：当季乙级 ≥ 5 已进 S4 的，期满后不再因 ≥ 3 二次进 S3——该季的乙级计数在出 S4 时清零，重新累积。

**「超规模亏损」怎么算。** S4 的重启触发不是「亏了 10%」，是「亏得比规则允许的还多」。建仓日算式允许的最大证伪损失 ＝ 建仓日算式上限 × 建仓日证伪损失假设。案例账户一腿、0 次兑现：15% × 65% ＝ 9.75%。按规下注、按规兑现、结果是亏——亏 9.75% 以内不触发重启，只按连亏两笔处置。只有当你下注超过当时的上限，或未在三日内兑现导致亏损扩大，实际亏损才会超过这个数——那时重启才是对的。这一条把「做对了却被罚」从系统里删掉。

三点说明。**警戒不是惩罚，是数字越线。** 现金、因子、单票三个数任一越线就进入，回到限内一周就退出；它只锁住「放大」这一类动作。**停手分两级。** 一周级的出口是常态（先重评 S3），一月级与超规模亏损的出口是试炉——从可投资金一成重新开始（C01-015），因为后两种情形说明的不是一次运气差，是选择或规模出了问题。**试炉不是新手期。** 任何从停手重启的人都回到试炉，不论经验；毕业条件是记录（五个 8/8、一次兑现），不是时间。

行是动作，列是账户状态。✓＝允许（仍受手册算式约束）；✗＝禁止；括号内是条件。仓位状态的额外限制见 2.2 表的「禁止」列，两表取交集。

越靠下的动作越「放大」，越靠右的状态越「收缩」——右下角全是 ✗：出问题时，你能做的只剩减少与记录。

## 2.4 每日四问

收盘后一次，五分钟。盘中不打开本系统。「笔」的定义：**一笔＝一个标的从首笔成交到清仓的一次完整持有**，已了结盈亏按该次持有的加权成本计；阶梯减仓与入场分批都不单独算一笔，也不计入连胜连亏；证伪卖出与认错价卖出算一笔。

```
问一 · 账户在哪？             读数                          → 状态
  现金 ÷ 总资产                 ≥ 两成（热区三成）？
  同因子持仓合计                ≤ 60%？
  每只持仓 ÷ 总资产             ≤ 本季上限？
  本月成交笔数                  ≤ 3？
  最近连胜／连亏                连赢三笔？连亏两笔？
  当季记点                      乙级 ≥3？≥5？甲级？
  睡眠两栏                      连续两晚失眠／夜间看盘？
  本季热区判定                  D6 五问 ≥3 热？（热区只抬现金线，不直接进 S3）
  月度自查（月末读一次）         人声鼎沸？想不起最近哪次下跌让我紧张？账户创新高？
  → 全部「否」= S2；任一警戒项 = S3；任一停手项 = S4；三者并存取最高（S4 > S3 > S2）；S1 另按一成总额

问二 · 每个持仓在哪？          读数                          → 状态

  价格相对阶梯                  到档？→ P6

  = 2.3 矩阵的列（账户状态）∩ 2.2 表「禁止」列的补集（仓位状态）− 生效中的修饰符

```

四问的输出是**明日清单**——一张只含允许动作的纸。明天盘中出现的任何念头，若不在清单上，写下来，进入后天的三问（C07-009 隔夜）。

## 2.5 用状态机重走案例账户

手册第九章把案例账户的八个决策点逐一对照了系统；这里只看状态：

| 时点 | 案例账户的动作 | 状态机的读数 | 系统下会发生什么 |
|---|---|---|---|
| 建仓日（$110） | 70 单位一次性买入 | 五样东西 0／5 → 未过 P2；70 > 上限 15 → 宪二、宪三 | 不进入 P3；若已成交：甲级，S4 一周，按 R7.4 分三次降到 15 |
| 涨到 $180 | 减半 | 已过阶梯第一档 $165 → P6 | 卖原始股数 25%；减半与阶梯方向一致，差别是没有预写 |
| 涨到 $250 | 追高加 10 单位 | P6 内加仓 → 禁止；无里程碑 → R6.2 条件① 无法核实；冷却期 → 宪六 | 该单不存在；若成交：乙级（同季第二次甲级），按 R7.4 降回 |
| $300 → $150 | 靠信念扛住 | 自最近加仓价 $250 起 −40% → P5：−20% 跑清单，−30% 一页纸 | 清单未写 → 无法跑 → 视为触发未兑现（宪五）；有清单则按表动作 |
| $150 附近的煎熬 | 失眠 | 宪七：连续两晚 → 超限 | 减到上限，不论论点；实测承受线记 30% |
| $210 仍持有一半 | 「非常看好」 | P4；持有理由栏为「看好」→ 讲不清（宪十一）；无清单 → 无四把尺 | 季度复核日补齐五样，否则该仓按投票机仓计，上限 5.7 |

同一笔交易在系统里的路径：P2 过不了 → 不会有 70 单位；即使有，建仓日就是 S4；即使扛到 150，宪七会在失眠的第二晚把仓位减到 15。煎熬在系统里没有发生的位置。

## 本章一句话

状态不是对你的评价，是今天的边界；边界之内你自由，边界之外没有「例外」这个词。
