# 第七章 · 执行矩阵：三百六十条纪律的机制

> 天网恢恢，疏而不失。　——《道德经》第七十三章

前六章是机器的结构；本章是机器的完整性证明。《投资纪律总表》的每一条纪律在这里有且只有一行：**检查时点**（何时查）、**检测器**（靠什么发现违反——纸面、数字、时钟、记录、身体、他人）、**违反后果**（做什么，记哪一级）、**机制**（由哪条宪法、哪条手册规则、哪条 R18 新增规则或哪条裁决承载；不采纳的写理由）。三百六十行由脚本核对：矩阵的编号集合必须与纪律总表的编号集合完全相等，一条不多、一条不少。

四种处置：**采纳**——纪律原样进入机制；**裁决限定**——纪律被第四章的某条裁决替代或限定了适用条件（例如常数换算式、价格尺只对投票机仓）；**不采纳**——A 股专属制度、面向定投或非深研路线且与本系统读者相斥、或与裁决默认相反的一方，理由写在机制列；**原则化**——审查判为纪律但实际不可检测的条目，作为理由保留、不作规则。四种处置都算「有去处」；本系统不允许一条纪律没有去处。

读法：按编号查；「机制」列的引用可以直接翻到对应章节。矩阵的行是语料的，列是本系统的——语料说做什么，本系统说怎么保证你做了。
