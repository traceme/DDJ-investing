# 第六章 · 接口：四层文本怎么一起用

> 执古之道，以御今之有。　——《道德经》第十四章

本项目现在有四层文本。它们不是四本要分别读完的书，是一台机器的四个部件，各有职责、各有编号、互相引用。本章说明谁引用谁、参数放在哪、一个新读者按什么顺序进入、每天实际翻开的是哪一层。

## 6.1 四层

| 层 | 文件 | 职责 | 编号体系 | 回答的问题 |
|---|---|---|---|---|
| 心法 | 五部语料（`chapters/`、`codex/`、`thethirdeye/`、`jinbing-drdj/`、罗盘长文）及两部合集 | 该相信什么 | 道N／CodexN／三眼N／金N／罗盘N／选N／全N | 为什么 |
| 法源 | 《投资纪律总表》 | 语料里全部可检查的行为约束，逐字核对来源 | C01-001 … C18-022（360 条） | 语料要求做什么、不做什么 |
| 算法 | 《道德经投资打法手册》 | 一笔交易的八个决策点：规则、算式、数字、填好的表 | R1.1 … R17.3（54 条）；参数表 | 怎么算 |
| 机器 | 《道德经投资系统》（本书） | 宪法、状态机、权限引擎、裁决、审计与修宪、执行矩阵 | 宪一…宪十二；S0–S4；P0–P8；R18.1–R18.20；§4.1–4.49 | 今天允许做什么、违反了怎样、什么时候能改 |

## 6.2 谁引用谁

```
 心法 ──抽取、归并、逐字核对──▶ 纪律总表（Cxx-nnn）
                                    │
                    ┌───────────────┼──────────────────┐
                    ▼               ▼                  ▼
              打法手册（R）    系统·宪法（宪）    系统·裁决（§4）
              算式与数字        十二条铁律          47 处分歧的默认＋2 补
                    │               │                  │
                    └───────┬───────┴──────────────────┘
                            ▼
                   系统·执行矩阵（第七章）
                   360 行：Cxx-nnn → 检查时点 → 检测器 → 后果 → 机制（宪／R／R18／裁决／不采纳）
                            │
                            ▼
                   系统·状态机 + 权限引擎 + 审计
                   今天允许什么；权限怎么变；遵守了多少
```

三条引用规则：**手册的 R 规则在本系统里只引用不重写**——算式只有一个版本，在手册里。**纪律总表的编号是唯一法源**——本系统任何一条规定都能追到至少一个 Cxx-nnn，矩阵反向保证每条 Cxx-nnn 都有去处。**参数只有一张表**——手册 BOOK_SPEC 第 1 节，本系统只新增（★ 标出，见卷首），不改动。

## 6.3 手册与系统的分工

| 问题 | 在手册 | 在系统 |
|---|---|---|
| 这笔仓位该多大 | R4.1–R4.6 算式 | 宪二把算式的输出定为上限；§3.2 说明上限何时能变 |
| 什么时候卖 | R8.1 四把尺；R6.1 阶梯 | 宪五规定执行时限；宪六规定价格的资格；P6／P7 状态 |
| 跌了怎么办 | R7.1 回撤协议 | P5 状态的禁止项；宪七、宪八的检测器 |
| 能不能加 | R6.2 四条件 | 2.3 矩阵：警戒与停手中不能，不论四条件 |
| 什么时候复核 | R16.1 季度复核日 | §5.2 把复核日扩成十八项议程，并加月、周、年 |
| 怎么变强 | R17 训练路径、机制阶梯、信念系数 | §3 把三者与违规记点、罚扣合成一个权限引擎；§3.5 加了降级 |
| 语料的 234 条实操建议去了哪 | 附录 B 逐条换算 | 不重复；本系统的矩阵对应的是 360 条纪律（含 234 条实操建议的全部规则内容） |
| 信息、研究、复盘、学习、制度 | 手册不覆盖 | R18.3–R18.8、R18.13、R18.14、R18.18–R18.20 新增；矩阵 C09、C11、C17、C18 四类 |

## 6.4 每天翻开的是什么

| 时刻 | 翻开 | 做什么 |
|---|---|---|
| 收盘后五分钟 | 本系统 §2.4 三问 | 读数 → 状态 → 明日清单 |
| 想买一只股票 | 本系统宪三（一页纸）→ 手册第一至五章 | 五样东西：手册给算式，宪三给门槛 |
| 明日清单上有动作 | 手册对应决策点的表 | 按表执行；日志「依据规则条目」栏填编号 |
| 触发日 | 本系统宪五 → 手册 R8.1 | 收盘后决定、次日开始、三日内完成 |
| 月末 | 本系统 §5.2 月表 | 十项 |
| 季度复核日 | 本系统 §5.2 季表 → 手册表 11 | 十八项；唯一能上调上限的日子 |
| 年底 | 本系统 §5.2 年表 → §5.3 修宪窗口 | 十六项；三十天窗口 |
| 想改规则 | 本系统 §5.3 | 查层次与窗口；不在窗口一字不改 |
| 想知道某条纪律怎么落地 | 本系统第七章按编号 | 检查时点、检测器、后果、机制 |
| 检测器说「查某张表某一格」 | 手册附录 D 十四张表；本系统附录 D 九张 | 字段就是检测器：某格为空即视为未执行 |
| 想知道某条纪律从哪来 | 《投资纪律总表》附录 A 按编号 | 全部来源与逐字引文 |

## 6.5 新读者的进入顺序

1. 读本书第一章，打印一页纸。此时你已经知道系统不允许什么。
2. 读本书 §2.1 与 §2.4，判定自己在哪个账户状态。多数人在 S0——生存层清单有未勾的项。
3. 按 S0 的允许动作做：学习路径（R18.13），纸上空转。空转期间读手册第一至八章，每个想法走完八个决策点。
4. 清单全勾 → S1 试炉。第一笔实盘 ≤ 5%。此时才需要手册第九至十五章的模板与案例。
5. 五个 8／8 与一次兑现 → S2。此时读本书第三章，知道上限怎么挣；读第四章，知道分歧怎么判。
6. 第一个季度复核日 → §5.2 季表；第一个年底 → 年表与修宪窗口。
7. 《投资纪律总表》不需要通读；它是被引用的，按编号查。

## 6.6 本系统不做的事

不解释市场；不预测；不荐股；不给个性化建议；不重写手册的算式；不复述纪律的全文；不替你选标的、选行业、选时机。它只回答一个问题的三种形式：现在允许做什么、做了违规怎样、规则什么时候能变。

## 本章一句话

四层各归其位：心法说为什么，法源说做什么，手册说怎么算，机器说今天能不能。
