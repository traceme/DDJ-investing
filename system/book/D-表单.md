# 附录 D · 表单字段

执行矩阵的「检测器」列反复指向若干张纸：源头清单、研究笔记、日志、候选与放弃清单、资金进出记录、季度宏观体检、信用对账、记点台账、学习路径表。本附录给出它们的字段定义——**字段就是检测器**：某格为空，对应的纪律即视为未执行。手册附录 D 已有的十四张表（三条腿、清单、三档、仓位、三批、阶梯、一页纸、四把尺、日志、复核议程、年度审计、collar、基线）不在此重复；本附录只补手册没有的九张。

## D1 · 信息源登记表（月度清点用；R18.3）

| 字段 | 填法 | 支撑的纪律 |
|---|---|---|
| 源 | 名称与入口（年报、公告、原始披露、产业事实、自核数字、方法群） | C09-003 |
| 类型 | 源头／二手／情绪。二手与情绪不得作决策依据 | C09-004 |
| 首次登记日 | 日期 | — |
| 最近一次改变决策 | 日期；超过十二个月为空 → 本月删除 | C09-022 |
| 最近一次出现反对意见 | 日期（限方法群）；超过三个月为空 → 退出 | C09-021 |
| 替代了哪个旧源 | 新增源必填；写不出 → 不得新增 | C09-033 |
| 状态 | 在用／本月删除／已退出 | C09-063 |

每月清点：把「最近一次改变决策」超过十二个月的源删掉；确实没有可删的，在清点表写「本月无可删」即算完成（C09-063 的原话是「删一个不再用的」，不是「每月必删一个」）。荐股群数量必须为零，行情软件一个，推送全关（C09-001）。

## D3 · 每日日志（一行；R18.12）

```
日期 | 收盘后看账户(是/否) | 盘中开账户次数 | 资讯用时(分钟/上限) | 昨夜睡眠时长 | 夜间看盘(是/否) |
触发四栏(触发日 · 表内动作数量 · 执行日 · 实际数量) | 被拦下的冲动(一句) | 冷却期剩余天数 |
本日成交(标的·方向·依据规则条目·里程碑编号[加仓单必填]) |
错因(仅亏损日次日填: 三条自己的错 · 归层五类[分析/估值/仓位/纪律/运气] · 执行还是选择)
```

「依据规则条目」栏为空即视为无授权交易（C17-008）：未成交记乙级，已成交记甲级（宪三）。触发四栏是宪五与机制阶梯的唯一数据源（§3.1）：执行日晚于 T0 后第三个交易日，或实际数量少于表内动作数量，即未兑现。「归层」与「执行还是选择」并列填写——五类归层用于 R18.8，二分用于 C07-015 的「连续三笔选择错」（仅统计已了结亏损超过该笔成本一成的交易）。「资讯用时」超过自设上限即停（C09-023）。盘中开账户超三次 → 当天禁下单（C08-005）。

## D6 · 季度宏观约束体检（R18.19）

| 钟摆五问·估值分位 | 持仓加权价格相对基准档的分位，处于该类生意上一轮周期区间 ≥ 80% 分位 ＝ 热 | C12-015 |
| 钟摆五问·情绪温度 | D3「被拦下的冲动」本月次数 ≥ 上月两倍 ＝ 热 | C12-015、C11-014 |

### D8 附表 · 生效中的修饰符

状态之外的限制都登记在这里，每日四问的问三读它。

| 修饰符 | 来源 | 生效日 | 到期日或解除条件 |
|---|---|---|---|
| 下月主动买卖笔数减半（向下取整） | 当季乙级 ≥ 3 | | 下月末 |
| 下月不开新仓 | 基线三行任一低于上月 | | 下月末 |
| 下季不许换股 | 连续两次换股对照是卖掉的更好 | | 下季末 |
| 次年不上调任何上限 | 过程分均值 < 6／8；或风口占比 > 五成；或本季丙级漏项 | | 次年审计日 |
| 新仓第一批只许试错额度 | 过程分均值 < 6／8 | | 次年审计日 |
| 停开新仓一个月 | 连续三笔归因「选择错」 | | 满一个月 |
| 全部持仓算式上限 × 0.5 一个月 | 连亏两笔 | | 满一个月 |
| 仓位减半直到做得到 | 按规提现的钱不在账；亏损当天写不出错因 | | 补做当日 |

## D9 · 学习路径表（R18.13）

| 项 | 周期 | 记什么 | 阈值 → 动作 | 支撑的纪律 |
|---|---|---|---|---|
| 三张表功课 | 入市前一次 | 半年到一年啃熟资产负债表、利润表、现金流量表与几种估值法；写完一份完整推演 | 未过 → 停留 S0，不买个股 | C18-010、R18.1 |
| 持仓年报 | 每周两小时 | 日期、公司、章节或页码；连续读满一年 | 缺一周 → 丙级 | C18-018 |
| 行业深读 | 连续三个月每周两份 | 年报两份 ＋ 各写三条能用财报核对的行业事实 | 缺 → 丙级；该领域不得登记进研究清单 | C18-015 |
| 失败案例 | 每季一个 | 爆仓者／退市股／自己的亏损单，写三条死因 | 缺 → 该季不上调上限（丙级） | C18-016、R17.3 |
| 金融史 | 每月一本 | 书名、读完日期；不做下一根 K 线的预测 | 缺 → 丙级 | C18-017 |
| 九十天习惯 | 每天二十分钟 | 只记做没做；漏了当天补 | 中断 → 重新计时 | C18-021 |
| 消费品公司 | 每周一件 | 自己掏钱买过的东西：归哪家公司、靠什么赚钱、谁在抢生意，两百字 | 缺 → 丙级 | C18-022 |
| 读书推演 | 每本书 | 合上书用其方法把自己持仓从头推演一遍；推不动不算读过 | 推不动 → 不采信其结论 | C18-011、C18-012 |
| 研究领域登记 | 事件 | 已登记的两三个领域；新增须先完成「行业深读」三个月 | 超过三个 → 先退一个 | C18-002、宪十一 |
| 年度根本问题 | 每年 | 两三个持仓生意的根本问题及答案 | 缺 → 丙级 | C18-020 |
