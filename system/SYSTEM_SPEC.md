# 《道德经投资系统》书稿规格（SYSTEM_SPEC）

写手必读。本系统坐在三层文本之上：心法（五部语料）→《投资纪律总表》（360 条纪律，编号 `Cxx-nnn`，法源）→《道德经投资打法手册》（规则 R1.1–R17.3，算式层）。本系统是第四层：宪法、状态机、权限引擎、裁决、审计与修宪、执行矩阵。所有编号以本规格为准。

## 2. 宪法十二条（编号 宪一…宪十二，全书统一）

| 条 | 名 | 一句话 | 主要来源 |
|---|---|---|---|
| 宪一 | 本金 | 只用自有资金，任何杠杆不碰；五年闲钱；账外十二个月应急金；生活钱永不进账户 | C02-001/002/004、C03-001/002/003/014 |
| 宪二 | 上限 | 现金 ≥ 两成（热区三成）；单票买入时点 ≤ 算式上限、任何时点 ≤ 生存上限；同因子 ≤ min(六成, 承受线 ÷ 因子内最大跌幅)；宽基豁免；超限按 §2.1 削回表；上限只在季度复核日上调 | C01-001/002/003/013、C13-004、R4.1–R4.9 |
| 宪三 | 门槛 | 买入前五样写全：归类与三条腿、证伪清单、三档估值、仓位算式与三批、四个数；缺一不下单 | C04-007/011/013/028、C06-015、C17-007/008、R1–R5 |
| 宪四 | 静时立法 | 规则、阈值、认错价、估值只在平静时写、季度复核日改；盘中、下跌中、狂热中一字不改 | C17-001/002、C05-003/005、C06-001、R2.2、R7.2 |
| 宪五 | 触发即执行 | 清单命中、认错价触及、阶梯到档：收盘后决定、次日开始、第三个交易日前完成，不辩论 | C06-005/011、R2.3、R8.1 |
| 宪六 | 价格不是理由 | 涨不是买入加仓理由，跌不是卖出理由（投票机认错价与阶梯除外）；热闹处标的冷却七日；>20% 上涨后七日不建仓 | C07-003/006/020、C10-008、C06-004、C05-015、R6.3、R5.4 |
| 宪七 | 身体是检测器 | 连续两晚失眠、半夜看盘、需盯盘才敢持有＝超限，减到能睡着；承受线只降不升；吃掉健康家庭的交易当周清掉 | C01-006、C10-004/005/010、R7.3、R4.2 |

## 5. 执行矩阵（第七章）写法

每条纪律一行，按类别分 18 张表，列：

| 编号 | 纪律（≤22 字概括，不抄全文） | 检查时点 | 检测器 | 违反后果 | 机制 |

- **检查时点**：入市前／下单前／盘中／收盘后／触发日／每周／每月／季度复核日／年度审计／事件（写明事件）。
- **检测器**：违反了靠什么发现——纸面（某表某格有没有写）／数字（账户数据：仓位、现金、笔数、回撤）／时钟（日历到期）／记录（日志字段）／身体（睡眠等）／他人（搭伙人、家人）。写具体：例如「表 6 四个数格为空」「月末主动成交笔数 > 3」「D3 日志『错因』栏为空」。**表的编号有两套**：「表 1–14」＝手册附录 D 的交易表单，「D1–D9」＝本系统附录 D 的系统表单。
- **违反后果**：写具体动作与级别，例如「该单作废；记乙级」「仓位减半；记乙级」「停手一周；记甲级」「该季不上调上限（丙级）」。级别按 §3.3「条与级的对照」判定，判据是**有没有据此成交**：据违规输入或在禁止状态下成交＝甲级；纸面未完成或状态未处置＝乙级；节律漏做＝丙级。宪一、宪三、宪四、宪五、宪十的任何违反一律甲级。
- **机制**：写明它由什么承载，只能是以下之一或组合：`宪N`（被宪法吸收）／`Rx.y`（手册规则）／`R18.x`（本系统新增）／`§N.N`（本系统章节）／`裁决 §4.N`（被裁决替代或限定）／`不采纳：理由`（理由只能是：A 股专属制度（涨跌停、T+1、新股申购、配资、印花税）；面向定投或非深研路线且与本系统读者路线相斥；与裁决默认相反的一方；纯个人生活安排非投资行为）／`原则化`（作为理由保留、不作规则）。
- 每类表后一行统计：本类 N 条：采纳 a／裁决限定 b／不采纳 c／原则化 d。
- 不改纪律的编号、不合并、不遗漏；同一条可引用多个机制。

## 6. 文风与硬约束

- 对读者称「你」；案例称「案例账户」，账户＝100 单位；不出现真实金额。
- 规则 → 算式 → 数字；表格优先；不写不改变决策的句子；不解释市场；不荐股。
- 道德经引文逐字复制自 `原文/道德经-王弼本.md`，格式 `> 原文　——《道德经》第N章`（中文数字），每章 ≤ 2 处。
- 纪律引用写编号 `C04-012`；手册规则写 `R4.6`；宪法写 `宪二`；状态写 `S3`／`P5`。
- 每个文件一个 H1：`# 第N章 · 标题`；`## ` 节；`### ` 小节；不用 mermaid；ASCII 图放代码块。
- 不改本规格；不改纪律总表；不提交 git。
