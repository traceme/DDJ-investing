# 第一章 · 想法与论点

> 知人者智，自知者明。
> ——《道德经》第三十三章
>
> 知不知上，不知知病。
> ——《道德经》第七十一章

这两句在这个决策点上是同一条硬约束：**一个论点在写下「我知道什么」之前，必须先写下「我不知道什么」和「我凭什么比市场知道得多」。** 写不出后两项的想法，不是论点，是叙事。从叙事到论点只有一条路——把它拆成能分别被推翻的命题，逐条标明自己在这一条上是看得清还是看不清。

## 为什么

案例账户买入 NBIS 时的想法是一句话：AI 发展造成数据中心稀缺，NBIS 是新云里执行力最强的，财务比 CRWV 好很多。研究做了三项：财务状况、管理层执行力、团队背景。然后 100 个单位的账户里，70 个单位进了这一只股票。

这句话哪里不对？它没有一处是错的，但它没有一处可以被推翻。「稀缺」持续多久、到什么价格算不稀缺？「执行力最强」在哪个季度的哪个数字上能看出来变弱？「财务比 CRWV 好」是存量快照——现金多、负债少——它回答不了这门生意每投一块钱资本能赚回多少。三项研究覆盖的是同一条腿：这家公司能不能干。没有覆盖的是另外两条：这门生意值不值得干，以及干下去的钱从哪来、稀释多少。仓位却是按三条腿都成立定的。

后来的每一步都从这里长出来。$300 跌到 $150 的那些交易日，账户每天开盘都少一截，手里却没有一张纸写着「哪条命题被推翻了才算输」，能复核的只剩信念，于是靠信念扛。论点的形态决定了后面所有决策点有没有抓手：论点是一句话，后面就只能靠感觉；论点是三条腿，后面每一步都有变量可查。

## 想法从哪来，与想法怎么变成论点

想法的来源决定了它需要先过哪道门：

| 来源 | 例子 | 进入论点之前的门 |
|---|---|---|
| 自己的行业与产品经验 | 你写过的系统、用过的云、评测过的硬件 | 直接写三条腿；你的优势镜头通常就在这里 |
| 报表与渠道 | 财报里的异常科目、渠道反馈、竞争对手的动作 | 先做排除：写下最可能否掉它的那条理由，写不出就当没看过 [金43篇实操] |
| 热闹处 | 刷屏、连板、人人劝你上车 | 先冷却 7 个交易日，之后仍愿按自己的估值出价才进入论点 [道35章实操] |
| 已持有的仓位想加 | 「涨了想加」 | 空仓测试：假设今天没有持仓，还会按现价买吗？迟疑就不动 [道01章实操] |

想法变成论点的动作只有一个：把每条腿写成一句能被推翻的话。案例账户的三条腿写成命题是这样的——

- A：如果每 1 美元 capex 在合同期内换回的 ARR 与毛利能覆盖资金成本，这条腿成立；如果 GPU 租金下行的速度快于折旧回收，或新增 ARR ÷ capex 连续两季低于假设的 75%，不成立。
- B：如果已交付 MW 按计划兑现、前两大合同不被削减，这条腿成立；如果交付落后 2 个季度，或任一大合同被重谈，不成立。
- C：如果每次融资后的年化稀释率 ≤ 15% 且现金覆盖未来四季承诺 capex，这条腿成立；如果出现折价 > 30% 的增发，或缺口须靠未落实的融资填补，不成立。

「不成立」那一半写出来的瞬间，第二章的清单就有了一半。写不出那一半的腿，不是你看得太清，是你还没看。

## 规则

**R1.1 三条腿。** 论点拆为可分别验证的命题。默认三条：A 单位经济——这门生意每投一元资本赚回多少，能否在资金成本之上回本；B 执行力与竞争位置——它能不能比对手更快、更便宜地干成；C 融资与稀释——干下去的钱能否以可接受的代价取得。每条腿标两项：优势／盲区，已验证／未验证。第二部分四类模板可改腿名，不改腿数的下限——少于三条腿的论点，是没有拆完的叙事。

**R1.2 优势镜头声明。** 每条腿写一句：「我在这条腿上比市场看得清的是____，凭的是____。」写不出的腿按盲区处理；盲区腿的验证只能来自外部证据（报表、合同、渠道），不能来自你的判断。来源：[道71章实操] 的「我不知道」清单——写不出三条，说明还没想清。

**R1.3 里程碑拆解。** 任何需要超过 12 个月才能判决的论点，必须拆成 12 个月内可观测的里程碑，每个配数据源与预计日期。拆不出里程碑的论点，只能以试错额度 5 个单位持有 [金53篇实操]（R4.6）。

**R1.4 建仓当日归类。** 称重机仓：卖出尺是里程碑与证伪清单，价格不是卖出理由，仓位按第四章三个上限定。投票机仓：认错价建仓当日写死，跌破三个交易日内减完 [道42章实操][金58篇实操]，仓位按 2% 规则定——上限＝2% ÷ 认错幅度 [道06章实操]（R4.8）。不归类不下单；建仓后改归类＝被套后改口，记入复盘（R8.3）。

**R1.5 一腿优势只换基础上限。** 已验证的腿数决定信念系数（1 腿 1.0、2 腿 1.33、3 腿 1.67），系数乘的是基础上限（R4.4），封顶于生存上限（R4.1）。一条腿上的优势，永远换不来按三条腿定的仓位。来源：[金19篇实操]——仓位每往上加一成，先补一条你比市场多知道的事实，补不出来就退回去。

## 表格模板

### 三条腿表

| 腿 | 命题（一句可被推翻的话） | 优势／盲区 | 已验证／未验证 | 验证依据（报表／合同／渠道／自己的判断） | 12 个月内的里程碑 |
|---|---|---|---|---|---|
| A 单位经济 | | | | | |
| B 执行力与竞争位置 | | | | | |
| C 融资与稀释 | | | | | |

填法：命题栏必须写成「如果____，这条腿成立；如果____，不成立」的形式，写不出「不成立」那一半的，回去重写。验证依据栏只有四个选项，选「自己的判断」的腿一律标未验证。

### 优势镜头表

| 腿 | 我比市场看得清什么 | 凭什么（背景／数据／渠道） | 如果我错了，最先在哪个数字上显现 |
|---|---|---|---|
| A | | | |
| B | | | |
| C | | | |

填法：第三栏写不出具体来源的，第二栏作废。第四栏直接抄进第二章的清单，它就是那条腿的第一个证伪变量。

### 里程碑拆解表

| 里程碑 | 对应的腿 | 可观测变量 | 数据源 | 预计日期 | 验证后动作 | 逾期动作 |
|---|---|---|---|---|---|---|
| | | | | | | |

填法：预计日期精确到季度。验证后动作只能是「信念系数升一级」或「不变」，升级只在季度复核日生效（R4.9）。逾期动作固定为 R8.1 时间尺——逾期 ≥ 2 个季度且无对冲证据，减至上限一半。

### 归类表

| | 称重机仓 | 投票机仓 |
|---|---|---|
| 卖出尺 | 证伪清单＋里程碑（第二章、第八章） | 认错价，建仓当日写死 |
| 仓位定法 | min(生存上限, 基础上限 × 信念系数)（R4.6） | 2% ÷ 认错幅度（R4.8） |
| 持有期 | 最短服役期 12 个月 [金12篇实操] | 认错价与阶梯之间，不设最短 |
| 加仓 | 加仓四条件（R6.2） | 不加仓 |
| 回撤协议 | −20／−30／−50（R7.1） | 认错价即协议 |
| 价格的角色 | 只在估值锚里出现（第三章） | 唯一的尺子 |
| 归类日期与签名 | | |

填法：二选一，签日期。两栏都想要的仓位，按投票机仓定仓——它的仓位小得多，这是「都想要」的价格。

## 填好的例子：案例账户的 NBIS

账户 100 个单位。案例账户实际投入 70；下面是系统会怎么写。

| 腿 | 命题 | 优势／盲区 | 建仓时状态 | 验证依据 | 12 个月里程碑 |
|---|---|---|---|---|---|
| A 单位经济 | 每 1 美元 capex 换来的 ARR 与毛利能在资金成本之上回本，且 GPU 供给正常化后仍能维持 | 盲区（计算机出身，非资本市场） | 未验证——「财务状况好」是现金与负债的快照，不是回报率 | 自己的判断 | 连续两季新增 ARR ÷ capex 不低于基准档假设的 75%；GPU 小时租金跌幅在模型假设之内 |
| B 执行力与竞争位置 | 交付速度、自研硬件成本、客户获取优于 CRWV 与超大规模厂商自建 | 优势——能判断技术与工程的可信度 | 已验证（研究主体） | 自己的判断＋公开合同（2025-09 微软合同约 174 亿美元／5 年，核对） | 已交付 MW 不落后计划 2 个季度；前两大合同无削减、无重谈 |
| C 融资与稀释 | 增长所需资本能以可接受的稀释与利率取得 | 盲区 | 未验证——看了资产负债表，没看融资路径 | 自己的判断 | 每次融资后年化稀释率 ≤ 15%；现金覆盖未来四季已承诺 capex |

优势镜头：只有 B 腿写得出「凭什么」。按 R1.5，一腿优势 → 信念系数 1.0 → 仓位上限＝基础上限 15 个单位（R4.4：永久亏损预算 10 ÷ 证伪损失假设 65%）。案例账户的 70，是按三条腿全部验证、再乘上一个规则里不存在的系数得出的数。

### 「怕等不到」怎么解

案例账户后来承认：不确定 NBIS 是不是好生意，模糊觉得是，要 3–5 年才能证明，怕等不到。这是 R1.3 的典型场景——论点的判决期（3–5 年）长于持有能力（≤ 1 年）。解法不是延长耐心，是拆判决：

| 3–5 年才能判决的问题 | 12 个月内可观测的里程碑 | 数据源 | 频率 |
|---|---|---|---|
| 这门生意的资本回报率能否持续高于资金成本 | 每季新增 ARR ÷ 当期 capex 不低于基准档假设的 75% | 季报的 ARR 指引 vs capex 实际 | 每个财报季 |
| GPU 供给正常化后租金会不会塌 | H100／H200 级公开租金同比跌幅在模型假设之内 | 云厂商公开价表、第三方指数 | 每月 |
| 它能否比超大规模厂商自建更快、更便宜 | 已交付 MW 不落后计划 2 个季度；前两大合同无削减、无重谈 | 季报、电话会、公告 | 每个财报季 |
| 增长的钱会不会把股东稀释掉 | 每次融资后年化稀释率 ≤ 15%；现金覆盖未来四季承诺 capex | 融资公告、季报 | 事件驱动＋每季 |

你不需要等到最终判决，只需要等到下一个季度的数据：证据累积 → 信念系数在季度复核日升级（R4.6、R4.9）；证据触发 → 按第二章的动作减仓。而真正让等待成为可能的是仓位：15 个单位承受 −65%，账户亏 10，等得起；70 个单位承受 −65%，账户亏 45，痛感会在判决到来之前把你赶出场。**让等待成为可能的是仓位，不是耐心。**

### 投票机分支：诚实的替代方案

如果你不打算做里程碑纪律——不查季报、不盯租金、只想持有一个「AI 稀缺」的故事——这笔仓位的诚实归类是投票机仓：认错价建仓当日写死，例如 −35%；上限＝2% ÷ 35% ＝ 5.7 个单位（R4.8）。「模糊觉得是好生意」配 70 个单位，是以投票机上限的 12 倍、称重机上限的 4.7 倍，持有一个投票机赌注。两种归类都合法，两种归类都活得下来；不合法的只有一种：按称重机仓定仓，按投票机的方式持有。

## 常见违规与自检

1. **叙事当论点。** 自检：你的论点里有没有一条命题写得出「如果____就不成立」？一条都写不出，回到三条腿表。
2. **一腿优势换整个论点的仓位。** 自检：仓位上限用的信念系数，等于已验证腿数对应的系数吗？验证依据栏里有几条填的是「自己的判断」？
3. **用信心代替验证。** 自检：标「已验证」的腿，依据是报表、合同、渠道中的哪一种？说不出具体文件的，改回未验证。
4. **不归类就下单。** 自检：归类表签了日期吗？签的日期在建仓日当天或之前吗？
5. **判决期长于持有能力。** 自检：论点的最终判决要几年？里程碑表里最近的一个日期距今几个月？12 个月内没有里程碑的论点，仓位是不是 5？

## 本章一句话

叙事只能被相信，论点才能被推翻；耐心等不来判决，仓位才等得起判决。
