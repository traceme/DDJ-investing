# 第八章 · 卖出与复盘

> 知止所以不殆。　——《道德经》第三十二章
>
> 民之从事，常于几成而败之。　——《道德经》第六十四章

「知止」在这里不是止盈止损的止，是**事先知道在哪里停**——四把尺子建仓当天写好，到点执行，不殆。第六十四章补的是另一半：事情常常败在「几成」，也就是最后一步。买对了、拿住了、涨到了，然后在卖出这一步把前面的全部交回去——案例账户在 $300 没有任何尺子，在 $150 靠信念，在 $210 的持有理由仍然是「非常看好」。这一章把最后一步做成不需要你在场的一步。

## 为什么卖出必须交给尺子

卖出是全程自我最响的时刻。涨的时候，你不想卖，因为「还会涨」；跌的时候，你不想卖，因为「成本在那里」；横盘的时候，你不想卖，因为「非常看好」。三种情形下你都在场，三种情形下的理由都不是理由。

四把尺子各量一样东西，互不竞争：证伪尺量论点，估值尺量价格相对价值，时间尺量日历，组合尺量账户。任何一把触发就执行；一把都没触发，就持有——**持有是规则的决定，不是你的决定。** 由此，合法的持有理由只有两条：清单未触发，价格未到阶梯档。其余的话，包括「非常看好」，不出现在纸上。

另一件事发生在卖出之后：复盘。复盘记什么，决定你下一笔是变好还是重复。记结果，你会把运气记成能力；记过程，你才知道这笔钱是谁给的。记分表里最贵的一行是重犯：同一个错误第三次出现时，它不再是错误，是你的规则缺了一条——补规则，不补决心。

## 规则

**R8.1 四把尺**（任一触发即执行，不辩论）
- 证伪尺：第二章清单任一阈值触发 → 按清单动作，3 个交易日内 [道42章实操]。
- 估值尺：阶梯档位到达 → 各卖原始股数 25%；价格超过牛市档 30% 以上 → 只留核心 25%。触发日收盘后决定，次日执行。
- 时间尺：里程碑逾期 ≥ 2 个季度且无对冲证据 → 减到上限一半。季度复核日执行。
- 组合尺：某一因子敞口 > 账户 60% → 按超出比例削最弱论点。季度复核日执行。

**R8.2 最短服役期 12 个月**：12 个月内不因价格卖出——阶梯与触发除外 [金12篇实操]。这条规则的作用是把「一周到一年」这种没有归类的持有期变成非法。

**R8.3 复盘只记三项**：目标、纪律、重犯 [三眼150]。过程分＝八个决策点中事先写好的个数（满分 8）。结果单独一行，不参与评分。

**R8.4 清仓冷却**：清仓后 7 个交易日不开新仓 [金58篇实操]。这 7 天用来填复盘记分表；表没填完，新仓不合法。

**R8.5 年度审计**：每笔盈利记一句「几分靠判断、几分靠风口」，全年汇总 [道02章实操][金03篇实操]；连同过程分、兑现触发次数、实测承受线、费用率一起构成年度审计（第十六章）。

## 表格模板

### 四把尺（建仓当日填）

| 尺 | 量什么 | 触发 | 动作 | 时限 | 本笔的数字 |
|---|---|---|---|---|---|
| 证伪尺 | 论点 | 清单任一阈值 | 按清单动作 | 3 个交易日 | 见清单 |
| 估值尺 | 价格／价值 | +50%／+100%／牛市档；超牛市档 30% | 各卖 25%；超 30% 只留核心 25% | 收盘后决定，次日执行 | 三个档位价；牛市档 × 1.3 |
| 时间尺 | 日历 | 里程碑逾期 ≥ 2 季 | 减到上限一半 | 季度复核日 | 里程碑日期＋2 季 |
| 组合尺 | 账户 | 因子敞口 > 60% | 削最弱论点 | 季度复核日 | 60 |

### 同日多尺触发的优先级

| 情形 | 执行 | 理由 |
|---|---|---|
| 证伪尺与估值尺同日 | 证伪尺 | 论点损失大于价格损失；减得更多的那把尺子先执行 |
| 估值尺与组合尺同日 | 先阶梯，再看组合尺是否仍超 | 阶梯本身就在降敞口 |
| 时间尺与证伪尺同季 | 证伪尺 | 时间尺只是证伪尺的慢版本 |
| 任一尺与「再等等」 | 尺 | 「再等等」不是尺 |

### 投票机仓的卖出（与称重机仓分开写）

| 项 | 规则 | 本笔的数字 |
|---|---|---|
| 认错价 | 建仓当日写死，中途不下挪 [金58篇实操][道42章实操] | 认错幅度 35% → 上限 2% ÷ 35% ≈ 5.7%（R4.8） |
| 剧本兑现价 | 建仓当日写：剧本兑现时的目标价与兑现证据 | |
| 时间上限 | 剧本未在约定日期兑现 → 清仓，不等认错价 | 剧本日期 |
| 执行 | 认错价触及当日；剧本兑现价按阶梯 | |

投票机仓没有「扛」这个动作：它的持有理由是剧本还没到期，不是论点还成立。

### 归类与持有期

| 归类 | 持有期由什么决定 | 价格是不是卖出尺 | 定仓 | 认错 |
|---|---|---|---|---|
| 称重机仓 | 里程碑与清单 | 不是（阶梯除外） | R4.6 | 清单触发，3 个交易日 |
| 投票机仓 | 认错价与剧本 | 是 | R4.8：2% ÷ 认错幅度 | 认错价触及，当日 |
| 未归类 | 价格与情绪 | 说不清 | 说不清 | 「一周到一年」 |

「一周到一年」不是策略，是没有归类的症状。归类在建仓当日完成（R1.4），之后不许改口——建仓当日归类与今天说法不一致，就是你正在被套后改口。

### 复盘记分表（每笔，清仓后 7 个交易日内填）

| 项 | 内容 | 本笔 |
|---|---|---|
| 目标 | 建仓时写的目标是什么、达到没有 | |
| 纪律 | 每个动作出自规则还是感觉（逐笔标规则编号或「感觉」） | |
| 重犯 | 这笔里犯的错，过去 12 个月出现过几次 | |
| 过程分 | 八个决策点中事先写好的个数 ／ 8 | |
| 结果（不评分） | 盈亏 | |

### 过程分怎么打（八个决策点，各 1 分）

| 决策点 | 得分条件：建仓当日已写下 | 案例账户 |
|---|---|---|
| 1 论点 | 三条腿、验证状态、优势镜头、归类 | 0 |
| 2 证伪清单 | 变量／数据源／频率／阈值／动作 | 0 |
| 3 估值锚 | 三档、每股价值、安全边际 | 0 |
| 4 仓位 | 三个上限的算式与结果 | 0 |
| 5 入场 | 批次、触发、四个数 | 0 |
| 6 加减 | 阶梯三档价、加仓四条件 | 0 |
| 7 回撤协议 | −20／−30／−50 的触发价与动作 | 0 |
| 8 卖出 | 四把尺、里程碑日期、认错价（投票机仓） | 0 |

「事先写好」的判据是时间戳早于第一笔成交。事后补写的不算——补写的纸只会写出当时价格允许你写的东西。

### 年度审计清单

| 项 | 算法 | 阈值 → 动作 | 来源 |
|---|---|---|---|
| 可重复性 | 每笔盈利：几分靠判断、几分靠风口 | 风口占比过半 → 次年不许上调任何上限，当年收益不计入任何腿的证据 | [道02章实操][金03篇实操] |
| 过程分均值 | 全年各笔过程分平均 | < 6／8 → 次年不许上调任何上限，新仓第一批只许试错额度 5 | R8.3 |
| 兑现触发次数 | 清单触发并在 3 日内执行的次数 | 每累计 3 次，证伪损失假设下修 10 个百分点 | R4.5 |
| 实测承受线 | 全年最深回撤时的信号记录 | 取自报与实测的较低者 | R4.2 |
| 费用率 | 年费用 ÷ 本金 | > 1% → 交易次数砍半 | [道75章实操] |
| 重犯 | 同一错误全年出现次数 | ≥ 3 → 写成规则加入清单 | R8.3 |
| 因子敞口 | 年内峰值与超限天数 | > 60% → 次年季度复核加一项 | R4.7 |

## 填好的例子：案例账户

四把尺回顾（建仓 $110；三档示例口径：熊 $36／基 $150／牛 $262；上限 15）：

| 价格 | 证伪尺 | 估值尺 | 时间尺 | 组合尺 | 系统动作 | 实际动作 |
|---|---|---|---|---|---|---|
| $165 | 未触发 | 第一档 | — | — | 卖原始股数 25% | 无 |
| $180 | 未触发 | 档间 | — | — | 无 | 减半（临场） |
| $220 | 未触发 | 第二档 | — | — | 再卖 25% | 无 |
| $250 | 未触发 | 档间 | — | — | 无（不加仓区） | 加仓（追高） |
| $262 | 未触发 | 第三档 | — | — | 再卖 25%，留核心 | 无 |
| $300 | 未触发 | 未到 $341 | — | — | 无 | 无 |
| $150 | 未触发 | 档间 | 未到期 | 70 单位 > 60 | 组合尺：削超出部分 | 靠信念扛 |
| $210 | 未触发 | 档间 | 未到期 | 仍超 | 持有核心；遗留超限按 R7.4 | 「非常看好」 |

复盘记分：

| 项 | 本笔 |
|---|---|
| 目标 | 无——建仓时没有写目标 |
| 纪律 | 0 出自规则；$180 减半接近阶梯但不是阶梯；$250 加仓违反 R6.2 与 R6.4（减了又在更高价买回） |
| 重犯 | 「减了又追回来」：过去 12 个月出现次数待填；若 ≥ 3，写成规则 |
| 过程分 | **0／8** |
| 结果（不评分） | 盈利（$110 → $210，含减仓） |

**这笔钱是市场给的，不是流程给的。** 同样的流程放到下一只标的上，期望值由运气决定。

> 善者果而已，不以取强。果而勿矜，果而勿伐，果而勿骄。　——《道德经》第三十章

「果」是结果到了；「勿矜、勿伐、勿骄」是不把结果记成能力。复盘表把结果放在评分之外，就是这一句的表格形态。

## 常见违规与自检

1. **用结果给过程打分。** 赚了就觉得对。自检：记分表里「结果」那一行参与评分了吗？（不许。）
2. **「非常看好」作为持有理由。** 自检：持有理由是否只有两条——清单未触发、未到阶梯档？多出来的每一条都划掉。
3. **阶梯到了不卖，「这次不一样」。** 自检：档位价格是建仓当天写的吗？改过吗？改动有收盘后的时间戳吗？
4. **清仓后立刻开新仓。** 自检：上一笔的复盘记分填完了吗？没填完，7 个交易日不算数。
5. **时间尺无限顺延，「下季度就兑现」。** 自检：里程碑日期是建仓时写的，还是后来改的？改了几次？

## 本章一句话

知止，是四把尺子在建仓那天就写好的停；几成而败之，败的是把最后一步留给了自己。
