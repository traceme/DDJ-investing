# 第二章 · 证伪清单

> 其安易持，其未兆易谋。
> ——《道德经》第六十四章
>
> 图难于其易，为大于其细；天下难事必作于易，天下大事必作于细。
> ——《道德经》第六十三章

硬约束有两条。第一条来自六十四章：**清单只能在「安」与「未兆」的时候写**——建仓前，或者季度复核日；下跌中写的不是清单，是辩词。第二条来自六十三章：**「卖不卖」这件难事，必须拆成几件「这个数字有没有越线」的易事**——清单上的每一行都是一个查得到的数、一个阈值、一个动作，没有一行是「管理层执行力是否变差」这种要靠判断回答的问题。

## 为什么

案例账户在 $300 跌到 $150 的那段路上，手里能复核的东西只有一样：还看不看好。它没有一张纸写着「哪个数字越线了才算论点被推翻」，所以每一天的决策都要重新做，而重新做的材料只有价格和情绪。它扛住了——但扛住的理由是信念，不是证据；下一次，同样的信念也能扛住一只真的坏掉的股票。

清单解决的是一个具体问题：**把「错杀」和「逻辑已坏」分开** [道15章实操]。价格跌一半，两种情形长得一模一样，区别只在清单上有没有一行被触发。没有清单，两种情形只能用同一种方式处理——要么都扛，要么都割；有清单，错杀不动，逻辑已坏三个交易日内减完。清单是论点的另一半：第一章写下「什么算成立」，本章写下「什么算不成立」，两半都写完，论点才是完整的。

清单还解决一个更隐蔽的问题：辩论的时间。没有清单，辩论发生在触发日——最痛、最不适合辩论的那一天。有清单，辩论被搬到了建仓前和季度复核日，触发日只剩执行。

## 规则

**R2.1 每腿 ≥ 1 个可观测变量。** 每个变量配四样：数据源（具体到文件或页面）、复核频率、触发阈值、触发动作。可观测的定义：两个人在同一天查同一个源，会得到同一个数。「执行力变差」不可观测；「已交付 MW 落后计划 2 个季度」可观测。

**R2.2 阈值只在建仓前或季度复核日改。** 下跌中改、盘中改，一律无效——写下的止损位与仓位上限即「言善信」，盘中不许改，要改只能在收盘后复盘时改 [道08章实操]。本书把「收盘后」再收紧一级：只在季度复核日（R16.1），随三档估值一起改。

**R2.3 触发即执行，3 个交易日内。** 来源：[道42章实操]——跌破认错价就在三个交易日内减完，中途不许下挪。辩论只在复核日；触发日的任何辩论都记为违规（R8.3）。

**R2.4 需求侧与集中度必列。** 公司自己的变量只能证明公司没坏，证明不了行业前提还在。清单必须有一行看需求方（下游 capex、行业价格），一行看集中度（第一大客户占比与合同条款）。前提松动时，公司执行得再好也要减。

## 表格模板

### 清单

| 腿 | 变量 | 数据源 | 频率 | 触发阈值 | 触发动作 | 最近一次值 | 复核日期 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

填法：
- 变量：写成一个能算出来的数，或一个能核对的事件。
- 数据源：写到文件名（季报第几节、年报附注哪一条）、页面或指数名称；「新闻」不是数据源。
- 频率：季（随财报）、月（行业价格）、事件（融资、合同）、年（会计政策）。
- 阈值：从第三章的三档假设反推，见下一节。
- 动作：只从动作阶梯的五个动作里选。
- 最近一次值与复核日期：每次复核填一次，空着就是没复核。

### 动作阶梯

| 严重度 | 动作 | 时限 |
|---|---|---|
| 假设偏离，论点未破 | 重算三档（第三章）；基准档下调 ≥ 25% 则减至上限一半 | 季度复核日 |
| 一条腿的关键假设失效 | 减至上限一半 | 3 个交易日 |
| 一条腿被推翻 | 减至试错额度 5 | 3 个交易日 |
| 需要人工重估（红旗） | 进入 −30% 复核流程（R7.1）：清单＋重算＋一页纸 | 收盘后决定，次日执行 |
| 行业前提松动 | 不论公司执行如何，减至上限一半 | 3 个交易日 |

### 阈值怎么定

阈值不是拍的，是从第三章基准档的假设反推的：

1. 列出基准档估值依赖的三到五个假设（例如：新增 ARR ÷ capex 的比率、租金年跌幅、稀释率、交付进度）。
2. 对每个假设问：偏离多少、持续多久，基准档就不再成立？那个点就是阈值。经验口径：连续两季偏离 25% 以上，或单次事件偏离 30% 以上。
3. 把敏感性最高的两项标出来——各挪一个百分点，结论翻转的那两项 [道21章实操][Codex71章实操]——它们的阈值收紧到 15%，频率提到月。
4. 阈值一经写下，只在季度复核日随三档一起重算。

### 数据源的四个层次

| 层次 | 例子 | 性质 | 用途 |
|---|---|---|---|
| 公司披露 | 季报、年报附注、电话会记录、公告 | 可靠，但滞后一个季度 | 腿 A／B／C 的季度变量 |
| 行业价格 | GPU 小时租金公开价表、第三方指数 | 可靠，且领先 | 月度变量，最早报警 |
| 需求方披露 | 下游客户的 capex 指引、大客户财报 | 可靠 | 需求侧那一行（R2.4） |
| 一手渠道 | 渠道、竞争对手、离职中层的独立证据 [金08篇实操] | 需交叉验证 | 验证里程碑，不作触发 |

### 变量的三种常见写法错误

| 错误写法 | 为什么不合格 | 改写 |
|---|---|---|
| 「管理层执行力变差」 | 不可观测，两个人查不出同一个数 | 「已交付 MW 落后计划 ≥ 2 个季度」 |
| 「竞争加剧」 | 没有数据源，没有阈值 | 「GPU 小时租金同比跌幅超出模型假设 30 个百分点」或「前两大客户合同条款变化」 |
| 「估值太贵」 | 这不是证伪变量，是估值尺的事（R8.1）；把它写进清单会让你在上涨中卖掉论点没坏的仓位 | 删除；估值由第六章阶梯处理 |

### 复核记录

每次复核（季度复核日、月度价格检查、事件日）填一行。这张表是 R2.2、R2.3 能被审计的唯一依据，也是第十七章「兑现触发次数」的原始数据。

| 日期 | 复核类型（季／月／事件） | 触发的行 | 触发日 | 执行完成日 | 间隔交易日 | 是否计入兑现次数 |
|---|---|---|---|---|---|---|
| | | | | | | |

填法：间隔交易日 ≤ 3 的触发才计入兑现次数（R17.1）；超过 3 日的记为违规，进复盘「纪律」栏（R8.3）。没有触发的复核也要填——「无触发」本身是一条记录，它证明你复核了。

### 触发次数与仓位的关系

每兑现 3 次触发，证伪损失假设下修 10 个百分点，基础上限随之上调（R4.5）。这是全书唯一一条「执行纪律直接换仓位」的规则：清单不只是防守工具，它是你能持有更大仓位的资格证明。案例账户的兑现次数是 0——所以它的证伪损失假设按可信最大跌幅 65% 计，基础上限 15；一个兑现过 9 次触发的执行者，同一只股票的基础上限是 10 ÷ 35% ≈ 29。

## 填好的例子：案例账户的 NBIS 清单

与第一章三条腿对应。阈值为示例口径，按你自己的三档改。

| 腿 | 变量 | 数据源 | 频率 | 触发阈值 | 触发动作 |
|---|---|---|---|---|---|
| A | 新增 ARR ÷ 当期 capex | 季报：ARR 指引 vs capex 实际 | 季 | 连续两季低于基准档假设 25% 以上 | 减至上限一半 |
| A | GPU 小时租金（H100／H200 级公开报价） | 各云厂商公开价表、第三方指数 | 月 | 同比跌幅超出模型假设 30 个百分点 | 重算三档；基准档下调 ≥ 25% 则减至上限一半 |
| A | GPU 折旧年限变更 | 年报附注 | 年 | 公司延长折旧年限 | 红旗，进入 −30% 复核流程 |
| B | 已交付 MW vs 计划 | 季报、电话会 | 季 | 交付延迟 ≥ 2 个季度 | 减至上限一半 |
| B | 大客户合同变动 | 公告、季报（2025-09 微软合同、2025-10 Meta 合同，核对） | 事件 | 前两大合同任一被削减或重谈 | 3 个交易日内减至试错额度 5 |
| C | 年化稀释率 | 每次融资公告：股本、可转债转股价（2025-06、2025-09 两次融资，核对） | 事件 | > 15%／年，或折价 > 30% 的增发 | 减至上限一半 |
| C | 流动性缺口 | 现金 vs 未来四季已承诺 capex | 季 | 缺口须靠未落实的融资填补 | 减至试错额度 5 |
| 需求侧 | 超大规模厂商 capex 指引 | MSFT／GOOG／AMZN／META 季报 | 季 | 同一季度两家下调 | 不论公司执行如何，减至上限一半 |
| 集中度 | 第一大客户收入占比 | 季报 | 季 | > 60% 且合同条款变化 | 进入 −30% 复核流程 |

阈值的来路，以第一行为例：基准档假设 2026 年末 ARR 约 65 亿美元（示例口径，核对），对应每季新增 ARR 与 capex 的比率；若连续两季实际比率低于假设的 75%，基准档的 ARR 到不了，估值锚整体下移——这就是「连续两季、25%」的来路。租金那一行的 30 个百分点，是模型里租金年跌幅假设与实际的差：差到这个程度，A 腿的回报率假设翻转。

这张清单在 $300 跌到 $150 那段路上会怎么用：−20% 时跑一遍，九行都未触发 → 不动；−30% 时再跑一遍并重算三档 → 未触发 → 写一页纸「新钱按上限以这个价买不买」；−50% 时三腿逐条出示当前证据（R7.1）。全程没有一步需要回答「我还看不看好」。

## 常见违规与自检

1. **变量不可观测。** 自检：清单上每一行，两个人同一天查同一个源，会得到同一个数吗？
2. **阈值在下跌中改。** 自检：最近一次改阈值的日期是季度复核日吗？改动理由写进复核记录了吗？
3. **触发后辩论。** 自检：上一次触发到执行完成隔了几个交易日？超过 3 个的，记入复盘的「纪律」栏。
4. **只列公司，不列前提。** 自检：清单里有没有至少一行的数据源不是这家公司自己的披露？
5. **写了不复核。** 自检：「最近一次值」与「复核日期」两栏，最近一个财报季填了吗？空着的清单等于没有清单。

## 本章一句话

安时写清单，兆前定动作；难事拆作数，触发即执行。
