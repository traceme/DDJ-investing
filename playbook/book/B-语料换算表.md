# 附录 B · 语料规则换算表

本表把五部语料的 234 条实操建议（《道德经81章投资心法》81 条、Codex 版 81 条、金冰读书心法 72 条）逐条对到本书的规则编号与案例参数。四种处置：**沿用**＝原口径直接进入本书；**改口径**＝本书用不同的数字或条件，备注写明原因；**已覆盖**＝其内容被本书某条规则包含，不另立条目；**不适用**＝面向 A 股散户、定投者、基金买家或入市前、全职决策等本书读者之外的场景。同一条涉及多个决策点时，放在最相关的一组，规则栏用「／」并列另见的编号。「案例参数下的数字」一栏给出该规则在案例账户（承受线 30%、永久亏损预算 10%、NBIS 可信最大跌幅 65%）下的取值。

读法：语料标签在行首，可回查原文；本书规则编号见附录 A。凡标「改口径」的，本书的数字不比语料更宽松，只是把固定数字换成了由参数推出的算式。
