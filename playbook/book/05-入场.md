# 第五章 · 入场

> 慎终如始，则无败事。　——《道德经》第六十四章
>
> 豫兮若冬涉川，犹兮若畏四邻。　——《道德经》第十五章

入场是整笔交易里唯一完全由你决定时机与数量的动作，之后的每一步都是对市场的反应。「慎终如始」在这个决策点上是一条硬约束：建仓当天写下的东西——批次、四个数、减仓阶梯、认错条件——就是这笔交易的全部纪律，此后只执行，不新增。「豫兮若冬涉川」是另一条：踩冰过河的人不是不过河，是一次只把一只脚的重量放上去。

## 为什么

案例账户的入场是：$110，一次性，账户的 70，不择时。「不择时」没有错，本书不主张择时，第三章的价格带已经回答了「现在能不能买」。错在「一次性」：一笔把整个仓位放上去，等于宣布这个价格是你未来十二个月能拿到的最好价格；而你对这只年化波动率约 100% 的标的，只验证了三条腿中的一条。

一个场景。建仓后第三周，它跌了 22%。证伪清单跑一遍，没有一条触发——跌的是价格，不是论点。一次性建仓的人此刻只有两种动作：扛，或者加仓摊成本，两种都是被动的。分三批建仓的人此刻在执行第二批：同一个论点、便宜 22% 的价格、仓位从 5 到 10。同样的下跌，一个人在受刑，一个人在收货。区别不在心态，在建仓那天有没有写下第二批的触发条件。

分批还解决一个更根本的问题：**入场那天是你的信念最缺证据的一天。** 三条腿通常只验证了一条，其余两条要等季报、合同、融资公告。第二、三批的触发条件把「等证据」写进了建仓计划：证据来了才加，不来就停在第一批 [Codex15章实操]。

## 规则

**R5.1 三批入场。** 第一批 ≤ 仓位上限的 1/3。第二批的触发二选一：价格比第一批低 20% 且证伪清单未触发；或第一个里程碑验证且价格仍低于基准档。第三批只有一个触发：第二个里程碑验证且价格低于基准档。三批之和 ≤ 上限（R4.6）。案例参数：上限 15 → 5／5／5。

**R5.2 四个数写全才下单** [金19篇实操]：赢面几成、赢一次赚多少、输一次亏多少、占账户几成。赢一次按基准档算，输一次按熊市档算（第三章）。写不出的那个数就是你还没做完的功课。这四个数不是用来算仓位的——第四章已经算了——是逼你在下单前正视第三个数。

**R5.3 不择时可以，一次性上满不行。** 批次间距按波动率定：年化 σ ÷ √12 ＝ 月度一倍标准差，间距取它的七成，向 5% 取整。σ 取期权隐含波动率与近十二个月已实现波动率中的较大者。下单用限价；仓位越大，要求的安全边际越高 [Codex61章实操]。

| 年化 σ | 月度一倍标准差 | 批次间距 |
|---|---|---|
| 30% | 8.7% | 5% |
| 50% | 14.4% | 10% |
| 80% | 23.1% | 15% |
| 100% | 28.9% | 20% |
| 150% | 43.3% | 30% |

σ ≈ 100% 的标的一个月走 29% 是常态：−10% 是噪音，把第二批挂在 −10% 等于把计划交给噪音。

**R5.4 冷却。** 任何一次 > 20% 的上涨之后的 7 个交易日内不建仓 [道35章实操]。从热闹处听来的标的，七天后你仍愿按自己的估值出价才小仓介入；只因怕踏空而想买的，不买。冷却期内只做一件事：写清单和三档。冷却是给功课留的时间，不是惩罚。

> 乐与饵，过客止。　——《道德经》第三十五章

热闹本身就是饵。凡以「还会一直涨」或「怕再也不涨」为理由的单子，搁置三个交易日再议 [道16章实操]；三天后理由仍然只有价格，就不下。

**入场批次 ≠ 加仓。** 三批是建仓当天写好的计划，填满的是当天算出的上限。超出计划再买——不论因为跌了还是涨了——是加仓，走第六章 R6.2 的四条件。

## 表格模板

三批表（建仓当日填，此后只执行）：

| 批 | 触发条件 | 仓位 | 触发价或事件 | 执行日 | 已执行 |
|---|---|---|---|---|---|
| 1 | 清单齐、三档齐、四个数齐 | | | | |
| 2 | −N% 且清单未触发；或里程碑① 且价格 < 基准档 | | | | |
| 3 | 里程碑② 且价格 < 基准档 | | | | |

填法：第一批的触发只有「三样东西写齐」；第二批写两个触发，先到先用；第三批只写里程碑，里程碑必须是第二章清单里有编号的变量，不是新闻。第四批不存在——想写第四批，回第四章重算上限。

四个数表：

| 数 | 值 | 来源 |
|---|---|---|
| 赢面 | | 已验证腿数与三档概率 |
| 赢一次 | | 基准档 vs 买价 |
| 输一次 | | 熊市档 vs 买价 |
| 占账户 | | 本批仓位 |

## 填好的例子（案例账户）

参数：账户 100；上限 15（一腿验证、机制未证明：10% ÷ 65%，R4.6）；σ ≈ 100%；三档 熊 $36／基 $150／牛 $262（第三章示例口径）。

| 批 | 触发 | 仓位 | 价格 |
|---|---|---|---|
| 1 | 决定日：清单九变量齐、三档齐、四个数齐 | 5 | $110 |
| 2 | −20% 且清单未触发（≤ $88）；或里程碑①（首个大合同的爬坡数据落地）验证且价格 < $150 | 5 | ≤ $88，或里程碑日 |
| 3 | 里程碑②（融资条款落地、年化稀释 ≤ 阈值）验证且价格 < $150 | 5 | 里程碑日 |

四个数：赢面 55%（一腿验证）；赢一次 +36%（$150 对 $110）；输一次 −67%（$36 对 $110）；占账户 5。第三个数的含义：你买的是尾部（第三章凯利诊断），所以第一批只能是 5。

案例账户实际：一次性 70。系统：5，最多 15。差额 55 个单位从建仓那天起就在承担 −67% 的可能，而论点的另外两条腿还没有任何证据。

## 边界情形

**触发日与执行日分开。** 第二批的「−20%」按收盘价判定，次日以限价执行（R7.2）；大跌当日只记录、不交易（R7.5）。一只 σ 100% 的标的在一天内从 −12% 走到 −24% 是常态，盘中判定会把你在最差的价格上接进去。

**触发了价格，也触发了清单。** 第二批不执行。仓位停在第一批，转入第二章的触发动作（R2.3）。价格便宜从来不是覆盖证伪的理由——便宜 20% 的破论点还是破论点。

**里程碑到了，价格没到。** 先用里程碑改三档（R3.6）；改后价格仍高于基准档，第二批不执行，继续等。里程碑提高的是下个季度复核日的信念系数（R4.9），不是今天的买入许可。

**三批没填满，价格先到了阶梯。** 第一批 5 在 +50% 触发第六章阶梯第一档，按实际持有股数卖 25%；未执行的入场批次自动作废——价格已进入不加仓区（R3.5），此后只有里程碑加仓一条路（R6.2）。

**限价没成交。** 每批限价的有效期 5 个交易日，到期未成交不追价、不改限价；回到第三章价格带重新判定，价格仍在入场区就重挂，不在就作废。追价成交的那一笔，在复盘里记为「价格驱动」。

建仓日时间线：T−7 起冷却（如从热闹处听来）；T−1 写齐三档、九变量清单、四个数、阶梯、归类，缺一样推迟；T 日第一批限价；此后只等两种信号——价格触发或里程碑编号触发。

## 常见违规与自检

1. 第二批的触发写的是「跌了再看」——问：触发价是多少？写不出数字就是没写。
2. 第一批就上了上限的一半——问：第一批 ≤ 上限 ÷ 3 吗？
3. 因为「怕涨走了」把三批并成一批——问：这个理由在冷却规则里叫什么？叫怕踏空，[道35章实操] 给它的答案是不买。
4. 四个数里的「输一次」填的是止损位而不是熊市档——问：这笔是称重机仓还是投票机仓？称重机仓的「输一次」是熊市档到达时的亏损，不是你希望止损的位置。
5. 冷却期内建了「小仓」——问：小仓的 7 个交易日比大仓短吗？一样长。

## 本章一句话

一次上满，是把全部信念押在证据最少的那一天；分批入场，是让证据替你决定第二只脚何时落地。
