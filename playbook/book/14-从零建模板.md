# 第十四章 · 四类之外：从零建模板

> 道可道，非常道。　——《道德经》第一章
>
> 人法地，地法天，天法道，道法自然。　——《道德经》第二十五章

第十至十三章的四张模板是「可道之道」：说得出、写得下、能照填。但模板只对它描述的那种生意成立。一门生意落在四类之外时，硬约束只有一条：**不许把它塞进最近的模板。** 没有模板的生意等于零条腿被验证，按 R4.6 只许试错额度 5%，直到你按本章七步把模板从这门生意自己的结构里长出来——人法地，模板法生意，生意法它赚钱的方式。

## 为什么

案例账户之外的一个常见场景：一位读者用第十三章的企业软件模板去看一家电商平台。他填了 NRR、RPO、席位数——平台没有席位，RPO 是零，NRR 无从计算。他把空格划掉，留下「收入增速」一项，于是证伪清单只剩一个变量，阈值随手定在「增速跌破 20%」。三个季度后收入增速还在 25%，但平台的抽成率从 12% 降到 9%，利润先于收入坏掉。清单没有抽成率这一行，因为模板里没有。

反过来也一样：把 neocloud 的模板（ARR/capex、GPU 租金）套到一家医疗器械公司，你会盯着一个不存在的租金曲线，错过真正先坏的变量——手术量增速。**模板不是分类学，是「这门生意哪个变量最先坏」的预排序。** 分类错了，排序就错，清单看起来齐全，触发永远不来。

## 七步流程

每步一个可填的格子。七格填满，模板成立；任一格空着，这门生意停在试错额度。

| 步 | 格子 | 填法 | 空着的后果 |
|---|---|---|---|
| 1 | 靠什么赚钱 | 一句大白话：向谁收钱、收什么钱、他为什么付；再答三问——赚不赚钱、是不是真现金、贵不贵 [道19章实操] | 不许进入步 2 |
| 2 | 定价变量 | 利润＝量 × 价 − 成本，写出这门生意的三个变量与算式 | R1.1 的 A 腿无法成立 |
| 3 | 哪个先坏 | 对每个变量打三分：变化速度、可观测延迟、对利润的杠杆；总分最高者为第一证伪变量 | 清单有变量无顺序，触发失效 |
| 4 | 数据源 | 三层：公司披露（季报、电话会、KPI 附表）；行业价格（公开价表、第三方指数）；客户与对手（对手财报、客户财报） | R2.1 无法配数据源 |
| 5 | 阈值 | 从三档假设反推：触发线＝基准档假设 −（基准档 − 熊市档）÷ 2，连续两季 | R2.2 无法预写，只能在下跌中临时定 |
| 6 | 倍数基 | 按现金流形态选（下表） | R3.1 三档无法搭 |
| 7 | 可信最大跌幅 | 峰谷法为主，波动率法校验，两者取大，下限 60% | R4.1 生存上限无法算 |

### 步 3 的打分法

| 变量 | 变化速度（1 慢–3 快） | 可观测延迟（1 长–3 短） | 利润杠杆（1 小–3 大） | 总分 |
|---|---|---|---|---|
| 变量甲 | | | | |
| 变量乙 | | | | |
| 变量丙 | | | | |

总分最高者进清单第一行；总分相同取「变化速度」高者——先坏的比坏得重的更值得先盯。

### 步 6 的倍数基

| 现金流形态 | 特征 | 倍数基 | 三档的核心假设 |
|---|---|---|---|
| 订阅 | 合同锁定、收入可见 | EV/ARR，成熟后 EV/FCF | ARR 增速、NRR、FCF 率 |
| 消费制 | 按用量计费、波动大 | EV/收入（以 NRR 校正） | 用量增速、单价趋势 |
| 项目制 | 订单驱动、周期性 | P/E、EV/EBITDA、订单簿覆盖率 | 订单簿、毛利率 |
| 资本密集型出租 | 先投资本后收租 | EV/EBITDA、新增 ARR ÷ capex、ROIC 对资金成本 | 利用率、租金曲线、融资成本 |
| 交易抽成 | 平台收 GMV 的一部分 | EV/收入；盈利后 P/E | GMV 增速、抽成率、获客成本 |
| 耗材＋设备 | 装机后按次收耗材 | P/E、EV/FCF | 装机量、每次使用收入、使用次数增速 |

规则：**用公司自己指引所用的口径当倍数基。** 公司按 ARR 指引就用 EV/ARR，按手术量指引就用手术量推 EPS；换一个更好看的口径＝换了一套没人核对的假设。

### 步 7 的两种算法

- 峰谷法：取 ≥ 3 家同类在上一个完整周期（默认 2021–22）的峰谷跌幅，取中位数。
- 波动率法（无同类或上市不足一个周期时）：可信最大跌幅 ≈ 30% ＋ 年化波动率 × 0.5，封顶 90%（编者设定，示例口径）。年化波动率 60% → 60%；100% → 80%。
- 两者取大，下限 60%（R4.3）；加密相关 85%。

## 走一遍：一家手术机器人公司

以 ISRG 的公开结构为例，只作方法示范。事实截至 2026 年初，逐条核对。

| 步 | 填好的格子 |
|---|---|
| 1 靠什么赚钱 | 向医院收三笔钱：卖或租手术系统；每做一台手术收一次器械与附件的钱；按年收服务费。经常性收入约占八成（2024，核对）。三问：赚钱（高毛利，核对）；真现金（FCF 为正，核对）；贵不贵——留到步 6 |
| 2 定价变量 | 利润 ≈ 手术量 × 每台手术耗材收入 ＋ 装机量增量 × 系统均价 ＋ 装机量 × 年服务费 − 成本。三个变量：**手术量增速、每台手术耗材收入、装机量** |
| 3 哪个先坏 | 手术量增速：速度 3、延迟 3（季报即见）、杠杆 3 ＝ 9；每台耗材收入：2＋3＋2 ＝ 7；装机量：1＋3＋2 ＝ 6；竞争者份额：1＋1＋3 ＝ 5；报销政策：1＋2＋3 ＝ 6。第一证伪变量＝手术量增速 |
| 4 数据源 | 公司披露：季报的手术量增速、装机量、耗材收入；对手：竞争系统的装机公告（2024 年起有跨国器械厂商推软组织手术机器人，核对）；客户：医院资本开支指引；行业价格：无公开价表，以公司披露的每台手术收入替代 |
| 5 阈值 | 基准档手术量增速 14%、熊市档 7%（示例口径）→ 触发线＝14% −（14% − 7%）÷ 2 ＝ **10.5%，连续两季** → 减至上限一半；每台耗材收入同比下降连续两季 → 重算三档；对手装机量单季超过公司装机量增量的三成 → 进入 −30% 复核流程 |
| 6 倍数基 | 耗材＋设备形态，盈利、高 FCF → P/E 为主、EV/FCF 校验。三档：熊 35× 前瞻 EPS、基 50×、牛 65×（示例口径，须按当期 EPS 与历史区间重算，核对）；公司按手术量指引，EPS 由手术量推出 |
| 7 可信最大跌幅 | 峰谷法：ISRG 2021-11 → 2022-10 ≈ −49%；ALGN 2021-09 → 2022-10 ≈ −76%；DXCM 2021-11 → 2022-06 ≈ −60%；EW 2022-04 → 2022-10 ≈ −49%（均凭记忆，核对）→ 中位数 ≈ 55%。波动率法：年化约 35% → 30% ＋ 17.5% ＝ 47.5%。两者取大 55% → 触下限 **60%** |

七格填满，模板成立。三条腿由此改名：A 手术量经济（步 2、3）、B 系统与耗材的竞争位置（步 4 对手项）、C 医院资本开支与报销（步 4 客户项）——腿名跟着生意走，编号与规则不变。生存上限＝30% ÷ 60% ＝ 50%；基础上限起始＝10% ÷ 60% ≈ 17%；一腿验证时仓位上限 17%（R4.6）。

### 两条补充规则

- **跨类的生意**：一家公司横跨两类（例如同时做经纪与加密交易），可信最大跌幅取较高的那一类，证伪清单把两类的第一证伪变量都列进第一行。取低者等于按最安全的那一半给最危险的那一半定仓位。
- **模板到期**：公司改变了收钱方式——从卖设备改为按次收费、从抽成改为订阅——旧模板作废，重走七步；重走期间仓位不上调，已验证的腿归零重验。模板法生意，生意变了，模板跟着变；用旧模板盯新生意，清单里的每一行都还在，只是没有一行还指着会先坏的东西。

## 常见违规与自检

1. 硬套最近的模板——**这门生意的第一证伪变量在模板里有没有那一行？** 没有就重建。
2. 倍数基挑好看的——**公司指引用的是这个口径吗？** 不是就换回去。
3. 峰谷取自平静期——**用的是上一个完整周期的峰谷，还是最近两年？** 不足一个周期用波动率法。
4. 步 3 不打分——**清单第一行是总分最高的变量吗？** 不是就重排。
5. 一句大白话说不清——**去掉行业名词后，「向谁收什么钱、他为什么付」还成句吗？** 不成句，停在 5%。

## 本章一句话

模板是可道之道，生意是常道；四类是地图，生意是地——**人法地：模板从生意长出，不是生意往模板里塞。**
