# 第七章 · 回撤协议与心力

> 故飘风不终朝，骤雨不终日。　——《道德经》第二十三章
>
> 重为轻根，静为躁君。　——《道德经》第二十六章

飘风骤雨有期限，但等它自己停，你未必还在场——它停之前，痛感可能已经替你清了仓。第二十三章说的是回撤的**形态**：剧烈的东西不持久；第二十六章说的是回撤中的**姿势**：重与静是根，轻与躁是失控的开端。这一章把两句话换算成一份协议：跌到哪一档、做哪个动作、不做哪个动作，全部在建仓当天写好——因为它要在你最不适合做决定的那一天执行。

## 为什么要有协议，而不是「到时候看」

案例账户在 $300 到 $150 的路上做了什么？什么都没做——靠「非常看好」扛过去。结果对了（价格后来回到 $210），过程是空的：没有一个动作出自规则。同一个「非常看好」放在论点已经坏掉的标的上，会把账户送到 −60%，而你在当时分不出两者的区别，因为你没有工具去分。

回撤中人的判断力是全程最差的：注意力被价格抓走，能想起来的只有信念和成本。协议不替你判断，它把判断挪到你还清醒的那一天。它只回答一个问题：**这次下跌是论点在坏，还是价格在动？** 前者按证伪清单执行，后者按承受线扛住。两者都不需要在跌的时候想。

一个前提要先立住：**回撤从成本起算（建仓价或最近一次加仓价），不从峰值起算。** 峰值回撤已由减仓阶梯处理——涨上去的部分按第六章的档位落袋，剩下的核心仓从设计上就不看峰值；成本回撤才是论点受质疑的信号。案例账户的 $300→$150 之所以成为协议事件，是因为 $250 那笔加仓把参照价抬到了 $250：$150 相对 $250 是 −40%。没有那笔加仓，$150 相对 $110 是 +36%，协议根本不触发。**制造回撤的不是下跌，是那笔不该存在的加仓。**

> 孰能浊以静之徐清﹖　——《道德经》第十五章

浊水不是搅清的，是放着让它自己清。协议里每一档的第一个动作都是「跑清单」而不是「做交易」，道理在此。

## 规则

**R7.1 三档动作**（自成本起算）
- −20%：跑一遍证伪清单。未触发：不动。触发：按清单的触发动作执行。
- −30%：清单＋用最新数据重算三档估值＋写一页纸「今天用新钱、按上限、以这个价，我买不买」。买：持有。不买：减到当前上限的一半。
- −50%：三条腿逐条出示**当前**证据。任一条未验证：减到试错额度 5%。
- 参数来源：档位为编者设定；试错额度 [金53篇实操]。

**R7.2 时间纪律**：只在收盘后决定，次日执行；盘中不改任何规则、阈值、认错价 [道08章实操]。改动只能发生在收盘后的复盘时段，改动日志留时间戳。

**R7.3 身体信号优先于论点**：连续两晚因持仓失眠、或半夜看盘，即视为仓位超限——不论论点如何，减到当前上限 [道13章实操]。这是实测承受线的反馈回路（R4.2）：身体报警时的账户回撤，就是新的实测承受线。

**R7.4 遗留超限**：已经超过上限的仓位，分三次、每次收盘后决定、间隔 ≥ 5 个交易日降到上限。证伪触发是唯一例外——触发则按 R2.3 三个交易日内执行，不等批次。

**R7.5 大跌日**：指数或持仓单日暴跌时，当天只记录不交易；隔夜后把持仓分成「错杀」与「逻辑已坏」两栏分别处置 [道15章实操]。错杀栏对照承受线，逻辑已坏栏对照清单。

## 表格模板

### 回撤协议表（建仓当日填，写进交易日志）

| 档位（自成本起） | 触发价 | 动作 | 不做的事 | 时限 |
|---|---|---|---|---|
| −20% | 成本 × 0.8 | 跑证伪清单；未触发不动；触发按清单动作 | 不复核「是否还看好」；不补仓 | 触发日收盘后 |
| −30% | 成本 × 0.7 | 清单＋重算三档＋一页纸 | 不用旧论点替新价格辩护；不改阈值 | 一页纸 3 个交易日内写完 |
| −50% | 成本 × 0.5 | 三条腿逐条出示当前证据；任一未验证减到 5% | 「看好」不算证据 | 3 个交易日 |

### 一页纸模板（−30% 档用）

逐条回答，任何一条答不出即视为「不买」：

1. 今天的价格相对**重算后**的基准档，是折让还是溢价？折让或溢价几成？
2. 证伪清单的每个变量，哪些变了、各变了多少？（逐行列出，不许写「基本没变」）
3. 三条腿各自的当前证据是什么？哪条腿的证据比建仓时弱？
4. 如果今天没有持仓——用新钱、按当前上限、以这个价——我买不买？买几成？
5. 我想持有的理由里，有几条属于「已经跌了这么多」「成本在 X」「非常看好」？划掉之后还剩几条？
6. 结论（三选一）：持有 ／ 减到上限一半 ／ 减到试错额度。
7. 执行日期（次日）与执行价区间。

### 三腿现证表（−50% 档用）

| 腿 | 建仓时的证据 | 当前证据（注明日期与来源） | 状态 | 动作 |
|---|---|---|---|---|
| A 单位经济 | | | 已验证／未验证／已证伪 | 任一未验证 → 减到 5% |
| B 执行力与竞争位置 | | | | 已证伪 → 按清单动作 |
| C 融资与稀释 | | | | 三腿均已验证 → 持有，重跑四个数 |

「当前证据」一栏只收带日期的数据与文件，不收判断句。「管理层很强」不是证据，「本季交付 MW 达计划的 95%（季报，年-月）」才是。

### 错杀／逻辑已坏分栏表（大跌次日用）

| 栏 | 判据 | 对照 | 处置 |
|---|---|---|---|
| 错杀 | 清单零触发；跌幅与因子同步（同类标的同日同向） | 承受线 | 不动；若价格跌入基准档以下且满足 R6.2，可按第五章批次买入 |
| 逻辑已坏 | 清单至少一项触发，或大跌由本公司事件引起且落在证伪变量上 | 清单 | 按触发动作，3 个交易日 |
| 分不清 | 两栏都填不满 | — | 视为逻辑已坏处理：先减到上限一半，季度复核日再定 |

「分不清」按坏处理，是这张表最重要的一行——回撤中给自己「再看看」的余地，就是把决定交还给当天的你。

有 collar 的仓位同样跑协议：地板只封住价格损失，不封住论点损失。地板到期（R15.6）之后，仓位若仍高于无保险上限，走本章的遗留超限流程。

## 填好的例子：案例账户 $300→$150

账户＝100。实际路径按「加仓 10 个账户点」读法重建；系统路径按第四章上限 15、第六章阶梯执行；其余仓位假设持平。

| 节点 | 实际路径 | 系统路径 |
|---|---|---|
| 建仓 | 70 单位 @ $110 | 15 单位 @ $110 |
| $165／$220 | —（$180 减半，临场） | 阶梯：各卖原始股数 25% |
| $250 | 加仓，参照价被抬到 $250 | 不存在（R6.2 三条件不过） |
| $262 | — | 阶梯第三档，累计卖出 75%，收回成本 148% |
| $300 峰值 | NBIS 占账户 62% | 核心仓占账户约 9% |
| $150 | 账户约 −31%；相对 $250 为 −40% → 协议 −30% 档在 $175 已触发 | 账户约 −4%；相对 $110 为 +36% → 协议不触发 |
| 做了什么 | 靠信念扛 | 什么都不用做——设计上如此 |

**煎熬不是心力问题，是 62% 与 9% 的差。**

实际路径若有协议：$175 触发 −30% 档，一页纸第 1 至 3 问要用重算后的三档与清单作答——案例账户建仓时既无三档也无清单，三问答不出，按模板规则视为「不买」，减到上限一半。这不是协议苛刻，是协议在调用第二、三章的成果：**没有清单和三档，回撤协议只剩一个动作——减仓。** 协议不是独立的，它是前面几章在最坏一天的执行入口。

实测承受线：案例账户在约 −31% 处报告「非常难过、煎熬」，记录表得出实测承受线 30%；自报 40%，按 R4.2 取 30%；生存上限由此定为 30% ÷ 65% ＝ 46%（第四章）。这一行记录的价值，超过那次回撤本身。

## 常见违规与自检

1. **跌了补仓「摊成本」。** 自检：这笔加仓满足 R6.2 四条件吗？跌幅本身是四条件之一吗？（不是。）
2. **−30% 时翻出建仓时的研究笔记安慰自己。** 自检：一页纸第 1 问用的是重算后的基准档，还是建仓时的？
3. **盘中改阈值或认错价。** 自检：改动日志的时间戳在收盘后吗？没有时间戳＝违规。
4. **失眠了，但「论点没变所以不动」。** R7.3 优先于论点。自检：过去两晚看盘几次？
5. **遗留超限「等反弹再减」。** 自检：三个处置日期写了吗？第一批在 5 个交易日内吗？

## 本章一句话

跌，要么是价格在动，要么是论点在坏：前者靠承受线扛，后者靠清单断——两者都不靠当天的你。
