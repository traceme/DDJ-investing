## 方法与底本

- **崇本息末**：沿用王弼《老子指略》的总纲，从生成结果的根本机制入手，不把章句简化成“耐心”“逆向”等口号。
- **原理先于类比**：每章先辨析原文，再建立因果链；明确哪些条件下推论会失效。
- **价值与生存并重**：企业端关注所有者收益、增量资本回报、护城河与诚信；组合端先排除永久损失和被迫卖出，再讨论收益。
- **证据可复核**：原文逐字取自 [`原文/道德经-王弼本.md`](/原文/道德经-王弼本.md)。思想参考包括[王弼《老子指略》](https://zh.wikisource.org/wiki/老子微旨例略)、[Stanford Encyclopedia of Philosophy: Laozi](https://plato.stanford.edu/entries/laozi/)、[Berkshire Hathaway 股东信](https://www.berkshirehathaway.com/letters/letters.html)、Barber 与 Odean 的[个人投资者交易研究](https://faculty.haas.berkeley.edu/odean/papers/returns/individual_investor_performance_final.pdf)，以及 Benartzi 与 Thaler 的[短视损失厌恶研究](https://www.nber.org/papers/w4369)。

## 贯穿八十一章的总纲

本版不把八十一章当成八十一条孤立格言，而把它们看作同一决策系统的不同切面：

| 道家概念 | 投资中的结构 | 每次决策要问 |
|---|---|---|
| 道与名 | 现实先于模型，模型必须可证伪 | 结论依赖哪些假设？ |
| 有与无 | 持仓创造收益，留白提供选择权 | 坏情景下是否仍能选择？ |
| 自然与无为 | 顺应商业经济性，以规则减少妄动 | 价值由企业创造，还是靠我择时？ |
| 反与复 | 成功改变条件，周期来自反馈 | 哪个约束会使趋势转向？ |
| 柔与弱 | 低杠杆、长资金、可更新 | 判断错了会不会出局？ |
| 朴与一 | 少数底层指标统摄复杂信息 | 现金流、竞争与资本配置是否一致？ |
| 知止与不争 | 守能力圈、估值与仓位边界 | 没有好价格时能否等待？ |

因此，“道”不是预测行情的秘术，而是一套先求不被单次错误消灭、再让价值与时间复利的决策秩序。
