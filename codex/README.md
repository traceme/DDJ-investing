## 写法与底本

- **从人情入道**：先讲每个人都经历过的等待、攀比、冲动、得失与自欺，再说明章句为何与投资有关。
- **从市场见心**：用追涨、重仓、杠杆、抱团、信息过载等具体场景，照见贪婪、恐惧和执念怎样接管账户。
- **先破后立**：不仅劝人“不要做什么”，还说明应当怎样研究企业、看待价格、安排仓位并守住能力圈。
- **知行合一**：每章正文以原文收束，再附一条不超过100字的实操建议，让读懂能够变成行动。
- **底本可核**：原文逐字取自 [`原文/道德经-王弼本.md`](/原文/道德经-王弼本.md)，保留其标点、校勘符号与异文处理。投资家言论只采用可核出处或明确标作转述。

## 贯穿八十一章的总纲

八十一章不是八十一种预测行情的技巧，而是同一件事的不同侧面：先把自己的心安顿好，再把钱交给看得懂的价值和足够长的时间。

| 道家概念 | 投资中的道理 | 每次下单前要问 |
|---|---|---|
| 道与名 | 标签不是事实，方法也会过期 | 如果没有持仓，我还会这样看吗？ |
| 有与无 | 仓位负责赚钱，现金负责让人不被逼卖 | 最坏情形来了，我还有余地吗？ |
| 自然与无为 | 好生意自己创造价值，投资者不必天天折腾 | 这笔收益靠企业成长，还是靠我猜涨跌？ |
| 反与复 | 涨多了会透支，跌深了会孕育机会 | 我是不是把眼前趋势当成了永远？ |
| 柔与弱 | 不杠杆、不死扛，认错后仍能留下来 | 如果判断错了，这一笔会不会伤筋动骨？ |
| 朴与一 | 把复杂故事还原成生意、现金与价格 | 这家公司究竟靠什么持续赚钱？ |
| 知止与不争 | 不懂不做，不贵不买，没有机会就等 | 这是我的机会，还是别人的热闹？ |

投资里的“道”，不是找到一招制胜的秘术，而是减掉妄念、守住边界、少犯大错。人不被贪惧牵着走，企业的价值和时间才有机会替人完成复利。
