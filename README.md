| 68 | 善战者不怒 | 被激怒的牛必败：不带情绪作战、不与市场硬顶、甘居下位借力，是不争之德。 | [第68章](chapters/第68章.md) |
| 69 | 祸莫大于轻敌 | 为客不为主、宁退尺不进寸，连胜时最忌轻敌——心存敬畏的哀兵才能笑到最后。 | [第69章](chapters/第69章.md) |
| 70 | 被褐怀玉 | 投资真理简单得没人肯信肯做，正因知我者希，坚守常识的笨功夫才藏着真金。 | [第70章](chapters/第70章.md) |
| 71 | 知不知，上 | 承认「我不知道」是投资体系的地基，过度自信的「我确定」才是最大的病。 | [第71章](chapters/第71章.md) |
| 72 | 民不畏威，则大威至 | 当市场无人再害怕时最大风险已在路上；别把生活压进账户，常留一分敬畏。 | [第72章](chapters/第72章.md) |
| 73 | 勇于敢则杀，勇于不敢则活 | 把「不敢」重估为更高的勇——敢空仓、敢错过、敢下撤者活，天网恢恢，市场的清算疏而不失。 | [第73章](chapters/第73章.md) |
| 74 | 代大匠斲，希有不伤其手 | 周期是市场的司杀者，看破泡沫不必替天执刀——重仓做空赌时点者，多半先伤自己的手。 | [第74章](chapters/第74章.md) |
| 75 | 无以生为者，是贤于贵生 | 账户之「饥」源于摩擦之税，投资者之「轻死」源于求生太厚——降成本、去杠杆、以闲钱投资方得长生。 | [第75章](chapters/第75章.md) |
| 76 | 坚强者死之徒，柔弱者生之徒 | 死扛不认错是僵硬而非坚定，柔韧快速纠错才是生路——处置效应的解药是向证据低头。 | [第76章](chapters/第76章.md) |
| 77 | 天之道，损有余而补不足 | 均值回归是天道张弓，追涨杀跌是人道逆行——在「有余」处克制、在「不足」处播种，别站在钟摆荡到最高的那一侧。 | [第77章](chapters/第77章.md) |
| 78 | 天下莫柔弱于水 | 复利与定投如水滴石穿，柔弱胜刚强的前提是先能「受垢」——承受浮亏与嘲讽者方为社稷主。 | [第78章](chapters/第78章.md) |
| 79 | 天道无亲，常与善人 | 报复性交易是与市场结怨，怨气会接管判断——执左契而不责于人，守纪律者才被天道「常与」。 | [第79章](chapters/第79章.md) |
| 80 | 甘其食，美其服，安其居，乐其俗 | 晒单攀比是「邻国鸡犬之声」，嫉妒驱动的换仓追高把本金丢在迁徙路上——安守能力圈，让复利长在自家田里。 | [第80章](chapters/第80章.md) |
