# 《投资三十二条军规》编辑规格

## 目标与边界

把本项目的投资纪律归纳为恰好三十二条有指导意义、附操作指南的军规。交付根目录同名 Markdown、EPUB、PDF，接入 Docsify 阅读与下载入口。正文面向自有资金的个人投资者，不提供标的推荐或收益承诺。

法源为 `system/data/纪律总表.json` 的 360 条纪律，同时吸收原则区 23 条、打法手册 54 条 R 规则、投资系统新增 20 条 R18 规则、心性指南 36 条 T 练习，以及量化设计的问题登记与执行约束。逐条归并，不把这些来源全部改称无条件铁律。

三十二条是新的编辑归纳，不替换原书参数、R/T 编号和策略版本。使用投资系统裁决理解旧口径；量化设计已经指出的模型、成交、版本冲突必须显式保留。年龄门槛、单一市场制度、固定收益预期不提升为普遍规律。

## 源文件与再现

- `book/00-卷首.md`：阅读方法与口径。
- `book/01.md` … `book/32.md`：恰好三十二条；H1 为“第NN条 · 标题”，装配时降为 H2。
- `book/33-案例.md`：虚构案例账户的完整决策过程。
- `book/34-操作卡.md`：五份可复制的操作卡及运行日历。
- `book/35-编者说明.md`：冲突、参数、市场与来源边界。
- `data/归并映射.json`：每条纪律唯一主归属，附吸收范围；补充 R/T/P/Q 对应关系。
- `assemble_book.py`：生成速查表、正文、完整编号索引和源文件指纹；`--check` 检查当前成稿是否与源文件一致。
- `validate_book.py`：核对 360/360 唯一归属、32 条完整结构、全部来源编号、建议长度、成书文本及导航。

每条含“军规”“为什么”“操作指南”“触发与处置”“实操建议”。操作指南有四步，建议少于 100 个非空白字符。每条目标 550–1100 个非空白字符（含来源前不含生成索引）。举例只用虚构名称和归一化单位；引文仅在确有必要时使用并逐字核对。

## 核验与构建

```sh
python3 system/render_catalog.py
python3 rules32/assemble_book.py
python3 rules32/validate_book.py
python3 scripts/build_system_epub.py rules32
python3 scripts/build_pdf.py rules32
python3 rules32/validate_book.py --artifacts
git diff --check
git status --short
```

结构校验不能代替内容审阅。另须通读每条归并后的正文、核对案例算术与冲突说明；渲染 PDF 全页联系表并检查代表页面；预览站内桌面与窄屏、EPUB 正文及目录。只构建本次新书，不重写其它书稿。发布时按用户授权提交新书、构建校验文件与站点入口，并在推送后核验线上阅读和下载。
