## 运行日历

| 时点 | 必做事项 |
|---|---|
| 每次买入之前 | 卡一有效，卡二更新，卡三全过；失败即不下单 |
| 收盘后 | 账户查看一次，记录事实、冲动、成交和次日预案 |
| 每周固定时段 | 成交与记录对账，检查睡眠和执行，读原始报告 |
| 每月结账 | 笔数、费用、反方台词、信息源、生活基线和归库检查 |
| 财报后五个交易日内 | 季度复核清单、估值、组合和权限；记录修订版本 |
| 每年固定审计日 | 目标、基准、购买力、全部账户、错误重犯与路线选择 |
| 证伪／失控／订单异常 | 事件优先处理，不能等到例行检查日 |

第一天先完成卡一并清理信息入口；第二天为最重要持仓补卡二和卡四；第三天把最近一笔交易放进卡三、卡五，找出一个实际缺口。先让一条纪律在真实记录里落地，再增加复杂度。
