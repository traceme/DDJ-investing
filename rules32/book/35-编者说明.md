# 编者说明 · 浓缩保留什么，取舍依据什么

## 归并的含义

本书将360条原纪律逐一归入三十二条，不把360句逐字缩短后重新排列。每条军规吸收一组相同决策问题，正文给操作条件，附录保留来源编号。唯一主归属用于检查遗漏；它不宣称每个原数字、每个修辞性禁令都成为本书的无条件规则。

原《纪律总表》核验的是所列2,526处摘引。核验通过不等于所有参数变体都有正确出处，也不等于适合自动下单。量化设计已登记部分变体标签越界及正文与表单冲突，本书不以摘引核验替代这些判断。

## 必须明说的口径

| 问题 | 本书处理 |
|---|---|
| 三年还是五年闲钱，现金留一成还是三成 | 示例沿用投资系统：高波动股票池五年闲钱、账外十二个月开销；账内现金普通20%、热区30%。不声称人人适用 |
| 单股永久亏损预算5%还是10% | 总表与手册属于不同口径；演练选总表5单位／100单位作较严示例，显式加入归零情景，不覆盖手册10%参数 |
| 兑现次数、信念系数能否扩大仓位 | 保留其训练思想，执行次数不自动降低市场尾部损失；额度上调仍需整体风险检查与版本批准 |
| 看跌幅、认错价还是企业价值 | 先归类；价格回撤可触发检查，投票机认错价和价值持有不可临场互换。账户与生活硬限制另外生效 |
| 止损应在24小时还是三交易日内完成 | 解释原系统的收盘决定、次日起执行、第三交易日前完成窗口；记录无法成交的现实，不承诺退出价和完成时间 |
| 固定止盈还是让好生意长期复利 | 两种版本分别保留，必须事先确定；原始股数、锚点和累计已执行档位不明，暂停相关自动计算，不临场拼接 |
| 同日多项减仓、热区连续存在 | 用事件编号和最终剩余目标处理；持续状态不反复记为新事件，同一股份不重复出售 |
| 最短持有期是否禁止一切提前退出 | 约束随意交易；硬证伪、重大诚信、账户限额与必要资金用途优先。此处吸收量化设计的边界补充 |
| 损失超过预算是否自动证明违规 | 否。先核对是否超仓、延误，也检查跳空、停牌、模型误差。流程违规与经济损失分开记录 |
| 亏损后必须写够三条错误 | 转为三项有证据的自查结论。查出错误要改，没有发现错误要写依据，不能虚构自责 |
| 四十岁后不能主动投资、跟踪两年才能买 | 不将年龄作一刀切门槛；按期限、能力与承受力选路。原系统把跟踪不足十二个月作为信念封顶，本书明确其来源与适用版本 |
| 盘中不下单、每月交易只限几笔 | 不在盘中创设主观交易；已批准预案可在交易时段执行。三笔为原系统审计线，降风险义务不受笔数阻挡 |
| 已实现利润还是浮盈提现 | 本书按已实现利润分配，属于编者归纳；原书特定盈利触发方案另用完整口径，不能靠借款或抽生活钱制造提现 |
| 物价与货币扩张怎样扣除 | 购买力使用明确的物价口径；货币供应只作背景，不与通胀重复相减 |
| 地区制度、牛市窗口与宏观指标 | 用于检查方法前提与结构风险，不普遍化为择时触发。市场未明确时不提供制度数值或产品清单 |
| 期权保险与宽基豁免 | 保险不自动保证账户地板或扩权；宽基的原书单票豁免不免除本书的组合暴露核算 |
| 试炉、停手与复训怎样恢复 | 临时冻结与基础资格分别核对。完整出口按选定版本执行，摘要与明细冲突不靠有利解释放行 |

这些取舍的共同方向是把条件、假设、实际执行写清，而不是把旧书的全部数字拼成另一套看似精确的机器。
