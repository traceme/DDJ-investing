# 第三只眼观 · 投资心法

本辑是《第三只眼观》（“三眼”系列文章合集）的逐篇读书笔记，共151篇：每篇先提炼原文**中心思想**（以「作者认为」的转述框架呈现，观点归属原书，是否成立请读者自辨），再转化为一篇**投资心法**随笔——把原书的生存视角落到周期、分配、流动性、情绪与风险管理的投资语言上。体例与[《道德经81章投资心法》](/README.md)一致。

> **免责声明**：本辑为读书笔记与投资常识的融合，不构成任何具体投资建议；文中提及的行业、资产与历史行情均为示例或史实复盘，不代表任何推荐。
