## 目标与方法

从本项目投资纪律和心法中找出原书欠缺的决策环节，融入[主书](/价值投资者投资体系与交易系统.md)，而非把旧书的金句、参数和个人经历拼接进去。先读总表命题识别覆盖范围与冲突，再通读浓缩纪律，回到相关源篇理解语境，最后检查“原则—流程—卡片—案例—复盘”是否衔接。

`buffett`技能用于检查成长与价值、持有与退出、心理与风险之间的逻辑，不将技能中的名言、经验比例或参数视为已核验的一手投资证据。

## 明确不移植的内容

| 原材料中的做法或表述 | 本书的取舍与原因 |
|---|---|
| 固定七分仓、留一至三成现金、单票固定上限等多种口径 | 不新增统一仓位或现金参数；保留已批准八项预警，按情景审阅组合 |
| 盈利50%/100%按固定比例兑现、翻倍收本金 | 不采用；本书成长价值路线依据论点、估值、集中度和用途判断 |
| 连胜三笔停一周、热区一律减仓 | 保留顺境复核，舍弃未经本账户批准的数字与自动卖出 |
| 每月仅一天交易、每月两笔或三笔 | 保留节律设计，不设强制配额，不能阻止必要风险处理 |
| 亏损后完全不动、所有动作都隔夜 | 改为限制计划外新增风险；已核实退出继续处理 |
| 冲动金额按四分之一折算 | 不采用；仓位从独立研究与风险预算重算，冲动不能成为计划基数 |
| 心性指南的赌徒分级、复训期限、转账延迟 | 不套用于本读者，不作心理诊断或疗效声称 |
| 睡眠/运动任一环比减少就次月禁止新仓 | 保留持续失衡的复核，不用单项噪声机械驱动交易 |
| “今天不买就全部卖”、最短持有期禁止提前退出 | 分清不新增与不持有；证伪、资金需要和风险约束优先 |
| 宏观水位确认后进场、只在牛市参与 | 只提取资金与产业约束，不生成择时信号 |
| 必须知道匿名卖家动机、推荐者全部持仓 | 只查公开可验证激励和证据，缺失记未知 |
| 亏损必须写三条自己的错 | 改为证据支持的归因，不编造自责；违规即使获利仍记录 |
| 四十岁禁入、生化行业一律不研究、固定成败比例 | 不采用；能力按具体问题检验，未核验比例不作为事实 |
| 名义收益再扣物价和货币增速 | 购买力选明确物价口径，不重复扣减 |
| 权限交给搭伙人、隐藏全部报价或所有通知 | 保留复核与降噪，不移交交易权、不关闭必要风险通道 |
