# 人生悟道 渡人渡己·投资篇 — 读书心法72篇

金冰《人生悟道 渡人渡己·投资篇（纪念版）》的读书笔记。原书正文七十二篇，选自「人生悟道 渡人渡己」系列约九百集投资主题节目，分基础、进阶、哲思三部。这里逐篇做两件事：先把那一篇讲的事情提炼成「中心思想」，再据此另写一篇独立成文的「投资心法」，最后落一条不超过100字的「实操建议」。

> **这是笔记，不是原著。** 中心思想、心法随笔与实操建议均为重新撰写；除少量注明出处、逐字可核的短引文外，不含原书文字。想读原书的读者，请直接读原书——「人生悟道 渡人渡己」是金冰先生发起的免费公开分享项目，音频、视频与文字稿见官方网站 drdj.net，喜马拉雅与 YouTube 同名分享。

## 体例

- **中心思想**：忠实概括原篇讲了什么，必须落到那一篇特有的例子、数字或比喻上，不写放到哪篇都成立的套话。
- **投资心法**：600–1500字随笔，从一个具体场景切入，进到真实的市场情形，先说清多数人错在哪，再回扣原篇主张，收在一句能记住的话上。每篇有两处下划线标注的定律式心法。
- **实操建议**：一段白话、100字以内，必须带触发条件、数字或可自查的规则。
- **引文可核**：正文中以高亮标出的短句逐字取自原书对应篇目，构建程序会回到原书 PDF 中逐字定位；核对不上即终止构建。高亮之外，任何与原书连续30字以上雷同同样会终止构建。
- **不荐股**：行业、公司、历史行情与资产类别只作行为的例证，不是推荐。
