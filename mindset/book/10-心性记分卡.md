# 第十章 · 为道日损：心性记分卡

**日期窗**：月末最后一个交易日（T10.1）、季度复核日（T10.2）、年度审计日（T10.3）。**出口数字**：月 12/12（写「不适用」也算填）、季 4/4、年 1/1。

> 「为学日益，为道日损。」　——《道德经》第四十八章
>
> 「知常曰明。不知常，妄作凶。」　——《道德经》第十六章

两条硬约束。为道日损：卡不记你读了多少、看对了几次，只记拦下了多少、删掉了多少临场判断，没有一格因账户涨了而变好看。知常曰明：没有上月的数，越线就判不出来。所以卡上没有收益率这一行。

## 为什么要一张没有收益率的卡

第 120 天，复核日前一晚。成交单第七行：第 63 天买入 C 1.5 单位；日记翻到那天写着「今日无」。你想把那三个字改成一条带强度的记录——交叉核就是为这一秒：成交单是权威，日记是自报，差异入账，不许倒着改。

> 在无法证伪的领域里，纪律是唯一可以被证实的东西。　——《第三只眼观投资心法》第44章

判断对不对要等几年还掺运气；今天开了几次账户、这单隔夜没有，当天可证。

> 只做纵向比较：不比别人今年翻了几倍，只比自己对生意、对周期、对人性的理解是否比去年丰满了一寸。　——《第三只眼观投资心法》第43章

只和上月并排，不和别人的截图并排（C11-003）。十二项里九项是语料要你数的行为计数，三项 ★ 指标（#10–#12）为两户结构与冲动日记而补，另有两处 ★ 阈值（#2 每日次数、#6 下限）。

## 对账交叉核

每月一次，五条（★编者设定）：① 成交单逐笔对日记，以成交单为准；② 无对应日记行的成交，该日完整率计「缺」，该笔同进转化率的分子与分母；③ 日记不许事后补写：载体必须当日写入即不可回改、带时间戳（发给自己的邮件、有版本历史的笔记），差异入卡、D3 补一行标「对账补」；换载体当场登记，未登记按该月完整率计 0；④ 样本 < 15 或完整率 < 70%，转化率写「不适用」；⑤「今日无」只进完整率，不进分母。

交叉核抓不到「有冲动、没成交、也没记」——#10、#11 是全卡仅有的两格纯自报，只用来判你不好：样本不足与完整率低只把等级按到学徒线以下（T10.2 两条封顶），换不来升档。

## T10.1 · 月度记分卡与对账交叉核

**触发**：月末最后一个交易日收盘后，与系统 §5.2 月表同日、同一张纸；60 分钟。

**动作**：① 填十二格，与上月并排，填不出的写「不适用」，不许空着；② 走交叉核五条；③ 越线项当场把修饰符登记到 D8 附表，来源栏写编号；④ 给第二把钥匙人发三个数（注资占比、甲级数、转化率）与当月日记副本，对方回一条抄回这三个数并注日期的「收到」，他那份你改不了；无此人时按第三章降级档执行；⑤ 抽一张卡纸上走一遍。

**计数**：十二格；对账差异条数。**达标**：12/12（「不适用」计入），差异全部入账。**逾期**：月末次日收盘前仍未填 → 该月完整率计 0 并登记丙级；连续两个月未填 → 登记「停开新仓 30 天（本书 T7.1）」。**支撑**：C11-024、C11-014、C11-015、R18.9。

## T10.2 · 季度等级与环境验收

**触发**：季度复核日（R16.1），系统季表十八项之后；2 小时。

**动作**：① 四项（#10 转化率、#8 本季甲级、#9 权重比、#11 完整率）各定档，取最低档为本季等级，写进季度复核记录；② 环境验收八项逐项截图：保证金关、期权无、日内关、推送关、守户无 App、自动转入与买宽基仍在、到价提醒只在预写价、群 0 软件 1；任一失败 → 当周修复并记「当季不上调任何上限（本书 T10.2）」；八项外加一行「信息源：荐股群 0、季看排名 ≤ 1」；③ 重写四张卡（T4.2）；④ 写一句身份句（T12.2）。

**计数**：四档；8 项。**达标**：等级入季度复核记录；8/8。**支撑**：R16.1、C11-003、C17-003。

四档的线是编者设定，不是诊断：任一项越赌徒线即赌徒，回停手期；四项全过守户线才是守户，其余学徒；守道另加年度三项。两条封顶先结算：样本 < 15、无第二把钥匙人的季度，等级最高学徒（同完整率 < 70%）——守户线本就写着「样本 ≥ 15」，天天写「今日无」换不来守户。

这张卡不改单笔仓位的算式（那由系统四本账算，R4.6），但它决定你今年能往操作户里放多少钱：赌徒 0、学徒一成、守户三成——你填出的四个数就是今年的可买额度。#10、#11 只能把你送回停手期；#8、#9、#12 由券商侧核。

## T10.3 · 年度心性审计

**触发**：年度审计日，系统年表十六项之后；半天。

**动作**：年表末尾加四行——① 四季等级曲线；② 失足与复发次数（D8 全年）；③ 提现的钱是否仍在不可投账户；④ 全部账户清单（银行、券商、交易类 App）交第二把钥匙人核对。重做 T1.1 十二问与第 3 天并排（示意：月均笔数 3.9 → 1.1，凌晨看盘 19 → 2 天）；只收紧的 ★ 参数提案写进修宪窗口（R18.17）。

**计数**：年。**达标**：1/1。**支撑**：C11-028、C03-017、R18.17。

## 常见违规与自检

1. 对账查出无日记行的成交，你补的是日记还是「缺」？D3 那行有没有「对账补」？
2. 卡旁边出现了收益率、排名或别人的截图？有一格写了本季赚多少，这张卡作废重填。
3. 这个月的卡是月末次日收盘前填的，还是月中补的？空两个月年末一次补齐＝十二格全是编的：第一个月完整率计 0 加丙级，第二个月「停开新仓 30 天」。
4. 十二格全绿而账户缩水两年，你还在看这张卡？该看三处：R2.1 的变量四季触发几次、是否都在 R2.3 的 3 个交易日内执行；里程碑（R1.3）逾期几季；连续三年跑不赢宽基（C11-016）。

## 本章一句话

胜人，账户替你记；自胜，只有你自己记——所以这张卡上没有收益率，只有拦下的次数、删掉的判断、守住的闸。
